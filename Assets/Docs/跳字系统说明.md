# 统一跳字系统

2026-10-06：伤害、治疗、Buff、未命中、被动提示与资源提示统一进入TipTextManager。

## 队列与时长

每个棋子有独立的消息队列，子节点的请求归入所属棋子。同一帧产生的伤害、被动和Buff一起显示，不等待前一条结束。新消息在下方，较早消息向上让位并继续滚动；不同目标可同时显示。状态与伤害结算立即执行，队列只管理文字表现。

rowSpacing默认2.4个世界单位，间距随相邻文字的字号增大。每帧维持上下间距，避免不同播放时长的文字追上彼此。排列仅移动动画轨迹，不重置显示寿命或淡出时间。

请求记录事件发生时的位置，目标移动、隐藏或销毁后，已排队消息仍在记录的位置播放，不会丢失致死伤害后的反馈。管理器禁用时清空队列并停止活跃跳字，销毁时释放它创建的对象池。

管理器durationMultiplier默认为2：普通提示使用现有预制体1.2秒，实际2.4秒；伤害以现有伤害预制体1.5秒为基准，实际3秒。文字先上浮，后半段淡出。统一使用现有TipText预制体，不再将伤害生成到独立ObjectPool.DAMAGE_TEXT池。

## 样式与调用

```csharp
var tips = BattleScene.Ins.BM.tipTextManager;
tips.ShowDamage(target, 120);                  // 数值越大，字号越大
tips.ShowDamage(target, 120, isCritical: true); // 默认红色
tips.ShowDamage(target, 120, color: Color.yellow, fontSize: 180);
tips.ShowTip(target, "充能完成", color: Color.cyan, fontSize: 110);
tips.ShowBuffAdded(target, "过载", 2, color: Color.yellow);
tips.ShowHeal(target, 30);                     // 默认绿色
tips.ShowMiss(target, fontSize: 105);
```

颜色、字号均可省略。普通字号默认100；伤害基础字号140，按140 + 20 × log10(伤害 + 1)增长，最高220。可在TipTextManager Inspector调整普通字号、伤害基础/最大字号、增长系数、普通伤害颜色与暴击颜色。显式传入的颜色/字号优先于默认样式。

UnitAttrCenter.TakeDamage传递AttackPack.isCritical，包含零伤害命中；负数伤害不显示。治疗默认绿色，其余提示默认白色。复用对象时重置颜色、字号、透明度和动画位置，避免暴击红色或大字号影响之后的Buff提示。

TipText关闭BestFit并允许文本溢出，以避免自定义大字号被预制体缩回100。原DamageText组件保留JumpOutNum(int)兼容入口，转发到统一队列；无战斗管理器的独立预制体也复用TipText表现。

## 验证

Tests/BattleRegression/Run.ps1共83项通过，其中12项跳字测试直接执行真实TipTextManager、TipText及UnitAttrCenter源码，覆盖伤害与Buff同时显示、上下排列、不同目标并行、字号增长、暴击颜色、样式复用、时长翻倍、位置快照、子节点归并、禁用清理、新消息不重置寿命、不同寿命保持间距及跨目标对象池复用。Unity场景依赖由替身提供。

全量游戏脚本编译通过。实际场景的字体清晰度、相机比例与长文本排版仍需试玩确认。
