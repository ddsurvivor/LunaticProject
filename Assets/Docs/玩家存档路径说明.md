# 玩家存档路径

玩家的 10 个 JSON 存档槽、游戏设置及全局通关记录统一保存到：

```text
Application.persistentDataPath/Datas/
```

按当前公司名 `PristineArchiveStudio`、产品名 `EI: Iris2`，Windows 默认位置为（产品名中的非法路径字符由 Unity 替换）：

```text
%USERPROFILE%/AppData/LocalLow/PristineArchiveStudio/EI_ Iris2/Datas/
```

实际路径以游戏 Console 中 `[DM] 存档目录：` 日志为准。路径不包含 SteamID，不依赖 Steam 初始化。

## 文件及新建流程

- `PlayerProfiles_0.json` 至 `PlayerProfiles_9.json`：玩家存档。
- `PlayerSettingsData.json`：游戏设置。
- `GlobalProgress.json`：独立于剧情槽位的通关标记；新游戏和读档不会清除。
- `GlobalProgress.json.bak`：全局记录替换前的本地备份，不需要同步。
- `.streamingassets_migrated`：旧目录一次性迁移标记。

首次运行自动创建目录和默认设置，没有存档的槽位保持为空。点击新游戏仍创建独立的 PLAYERPROFILE；在保存界面选择槽位后写入对应文件。直接调用 SaveData 或 InitSettings 也会确保目录存在。

首次读取全局通关记录时，若 JSON 不存在，会将旧 `PlayerPrefs` 键 `LunaticProject.GameFinished` 迁移到 JSON，成功落盘后删除旧键。已有 JSON 始终优先，不会被旧键覆盖。标题菜单“清除通关标记”会向 JSON 写入 false 并刷新背景，不删除剧情存档。全局记录读取损坏时会报错且保留原文件，不自动用默认值覆盖；显式清除可以重置该文件。

## 旧存档迁移

首次访问存档目录时，从 `StreamingAssets/Datas` 复制已有的 10 个槽位和设置文件，仅补充目标目录中缺失的文件，保留源文件。迁移标记避免后续启动重新导入已删除的旧存档。更早的其他公司名 persistentDataPath 目录不在本次自动迁移范围内。

正式发布包应排除开发用的测试存档，避免被新玩家导入。剧情、语言等只读资源继续从 StreamingAssets 读取。

## Steam Auto-Cloud 对应配置

| 字段 | 当前路径对应的值 |
| --- | --- |
| Root | WinAppDataLocalLow |
| Subdirectory | PristineArchiveStudio/EI_ Iris2/Datas |
| Pattern | PlayerProfiles_*.json |
| OS | Windows |
| Recursive | 关闭 |

这份规则只匹配玩家存档，不包含设置或迁移标记。本次只修改本地存储，未配置或验证 Steam 后台同步。同一 Windows 用户下的多个 Steam 账号目前共用本地存档。

若要跨设备同步通关标记，额外添加相同 Root/Subdirectory、Pattern 为 `GlobalProgress.json` 的规则。不要用宽泛的 `*` 匹配备份、临时文件和本机画面设置。第三方 Shader 插件的编辑器偏好仍由插件自行管理，不属于玩家进度。
