# 插件系统检查与调整

检查分支：dev。日期：2026-10-04。

## 现有插件与描述核对

| 插件 | 原问题 | 当前行为 |
| --- | --- | --- |
| 长远利益（5） | 能量返还只按技能基础费用计算，没有插件附加费用规则。 | 使用技能时35%概率返还本次完整能量费用，包括蛛丝的额外2点；施法前仍要求能量充足。 |
| 鞭挞（13） | 近战攻击在命中判定前恢复能量，未命中也触发。 | 普通近战实际命中敌人后恢复3点能量；每次攻击一次，多段/多个命中目标不重复。警戒、夹击共用结算。 |
| 内爆（3） | 命中前触发；技能资产实际为35%燃烧，与描述的30%过载不同。 | 普通近战实际命中后向命中方向触发一次敌方扇形能量伤害；资产保留原13点基础能量威力与范围，附加30%概率1层过载。额外攻击不会递归触发插件。 |
| 辅助线（4） | 配置为属性效果，但属性值为0；命中、闪避没有实现。 | 单体敌方攻击命中率增加30个百分点、闪避增加25个百分点。使用专用SingleTargetHitRate属性，实际结算和伤害预览共用，不修改范围技能必中规则。 |
| 蛛丝（6） | passiveType为None，没有费用与命中效果。 | 主动技能费用额外增加2点；命中后对全部被命中的敌方单位及至多两个不同的未命中敌方单位施加2层眩晕，并直接扣除15点生命。 |

蛛丝按每次技能结算触发一次，不按伤害段重复。随机候选排除死亡、不活跃、友方和认知防护目标，并对多碰撞体或重复列表去重。真实伤害不经过护甲、减伤和阻速场；被阻速场完全拦截的原攻击不计为插件命中。没有足够随机候选时使用已有候选；未命中、无伤害的辅助技能、普通近战/远程攻击不触发蛛丝。延迟技能在落地命中时触发，费用只在确认施法时支付一次。

## 结构与装备流程

- ComponentConfig保留已有编号与effectType；新增battleBonuses用于战斗属性加成，extraSkillMana用于技能附加费用。
- AttrBonus的attrId使用0至4：意志、作战、体能、沟通、模式识别。加成在AccessAttribute(Get)时计算，不写入永久基础属性，卸下不会扣除角色正常成长。
- PassiveEffect只加载有效的passiveType；ActiveSkill将skillPack加入当前棋子的可用技能。原技能资产与列表不被修改，卸下后恢复角色基础技能。
- ComponentEquipment统一枚举有效装备、计算属性与费用、刷新战斗单位以及接收命中结果。旧存档中的空槽数组可恢复，重复编号只加载一次，错误槽位中的插件不生效。
- TryEquip先验证背包持有、当前未装备、槽位类型与空位；失败不移除物品、不播放成功音效。TryUnequip只接受当前装备的编号，重复卸下不能生成物品。保留Equip/Unequip接口以兼容现有调用。
- 换装对插件属性进行撤销和重建，对角色派生属性仅应用差值，不重新初始化战斗单位。当前生命/能量不会因提高上限而自动补满；降低上限时将当前值限制到新上限。保留行动点、弹药、现有Buff和角色自身被动。
- 重复初始化不累加角色作战/模式识别带来的ATK、CON，也不重复添加插件技能或被动。
- 插件获得提示在首次添加成功时显示；未知配置编号不会进入背包。
- 技能可用性、扣费和悬浮提示使用相同的实际费用。装备失败时详情面板保留并显示原因。
- 配置提供ValidateConfiguration/OnValidate，报告重复编号、非法属性/槽位和未配置的主动或被动效果。
