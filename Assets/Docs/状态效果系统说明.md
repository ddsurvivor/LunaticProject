# Buff 系统与新增效果

现有流程：SkillPack.buffPacks 配置效果，BattleManager.PieceSkill 按概率和阵营调用 BuffManager.AddBuff。同类型叠加持续层数，首次添加/最终移除通过 ApplyBuff 增减属性。PlayerController.TurnStart 调用 ProcessBuffs 结算持续伤害/治疗并标记持续时间；PieceController.TurnEnd 调用 ProcessBuffDurations 扣除一层。仅扣除回合开始时已存在的状态，回合中新增状态保留到下一自身回合。燃烧仍在回合开始造成层数伤害并立即扣3层，阻速场仅消耗耐久。-1 为永续；掩体来源通过 RemoveBuffSource 独立移除。

## dev 分支检查与补全（2026-10-04）

已核对全部15种 Buff。过载此前只写入 MoveRangePercent，移动和 AI 没有读取该倍率；现在统一通过 UnitAttrCenter.MoveRange 读取，束缚与过载叠加时范围最低为0。

| 状态 | 实际效果 |
| --- | --- |
| 充能 | 增伤30%，伤害计算已接入。 |
| 自动治疗 | 自身回合开始恢复最大生命15%。 |
| 防护 | 减伤30%，伤害计算已接入。 |
| 隐蔽 | 闪避增加30%，影响非必中技能。 |
| 干扰 | 命中降低30%，影响非必中技能。 |
| 过载 | 移动范围减少50%，玩家和 AI 共用生效范围。 |
| 束缚 | 移动范围归零，阻止移动/攀爬确认。 |
| 燃烧 | 回合开始造成当前层数伤害，减少3层；永续燃烧每次造成1点伤害。 |
| 脆弱 | 动能护甲减少30%，输出伤害减少20%。 |
| 认知防护 | 敌方选敌和最终技能结算排除目标。 |
| 阻速场 | 消耗耐久阻挡敌方整次攻击与附加效果。 |
| 进攻性认知防护 | 被敌方有伤害段的技能攻击时，对攻击者施加反噬。 |
| 自发模因攻击 | 行动确认时扣最大生命15%，30%概率施加干扰/束缚/眩晕。 |
| 认知反噬 | 自身回合开始扣最大生命20%。 |
| 眩晕 | 清空行动点并禁止行动，聚能补满和行动点恢复不能绕过。 |

同时修正了以下接入遗漏：

- 普通一层 Buff 保留至自身回合结束，避免在行动前失效；回合中新增状态不提前扣层。
- 范围技能的 Self Buff 每次施法仅判定一次，地面技能或无有效目标时也可施加。
- BuffPack 的 FarthestEnemy、AllyBody 目标分支接入；死亡目标不接受新 Buff，复活后的状态应在复活后施加。
- HealArea 完整传递 barrierHealth、retaliationTurns。
- 掩体防护/隐蔽按独立来源持有，离开掩体保留技能层数；技能层数到期保留掩体状态。
- 单位重新初始化清除旧 Buff，避免对象复用后状态与属性不一致。
- 自爆召唤物接入自身阶段的 Buff 结算、行动异常、移动倍率及认知防护选敌，结束行动时结算持续层数。
- 无伤害段的敌方纯状态技能不触发认知反噬。

当前没有仅添加枚举、完全缺少效果实现的 Buff。图标仍需配置 SpriteManager.buffIconDic；具体角色技能是否使用新 Buff 属于技能资产配置。实时行动力充能组件尚无独立状态计时规则，本次沿用现有自身回合/召唤物阶段结算，不另行定义按秒持续时间。

## 新增配置

| BuffType | 效果与参数 |
| --- | --- |
| CognitiveProtection（认知防护） | 敌方 AI、技能目标预览、技能目标筛选与最终攻击结算均跳过该单位，包括范围攻击。友方效果不受影响。stacks 为持续回合。 |
| SlowingField（阻速场） | barrierHealth 为承伤耐久，0 使用 BuffManager.defaultBarrierHealth（默认100）。再次施加累加耐久；不按回合消失。按减伤后的攻击伤害扣耐久，破盾的整次攻击仍完全阻挡，包括多段伤害、附带状态和击退。Buff 数字显示剩余耐久。 |
| OffensiveCognitiveProtection（进攻性认知防护） | 被敌方攻击时给攻击者施加 MemeticRetaliation（认知反噬），未命中、被屏障阻挡也触发。retaliationTurns 为持续回合，0 使用默认3回合；重复攻击刷新到较长剩余时间，不累加伤害倍率。 |
| SpontaneousMemeticAttack（自发模因攻击） | 每次确认行动立即受到最大生命15%伤害，再独立进行一次30%判定；成功后等概率施加1层干扰、束缚或眩晕。致死中断行动；眩晕清空行动点，束缚中断移动/攀爬。 |

认知反噬每次自身回合开始扣最大生命20%，持续指定次数；两种百分比伤害向上取整，直接扣血，不经过护甲、阻速场。眩晕在自身回合开始清空行动点，回合结束才减少层数，因此1层会使下一个自身回合无法行动。

## 调用示例

```csharp
buffManager.AddBuff(unit, BuffType.CognitiveProtection, 2);
buffManager.AddBuff(unit, BuffType.SlowingField, barrierHealth: 150);
buffManager.AddBuff(unit, BuffType.OffensiveCognitiveProtection, 3, retaliationTurns: 3);
buffManager.AddBuff(unit, BuffType.SpontaneousMemeticAttack, 2);
```

SkillPack 的 BuffPack 可以直接选择以上枚举并填写参数。新枚举保留旧值，未改动已有技能资产或分配到具体角色；新图标需要在 SpriteManager.buffIconDic 中配置。
