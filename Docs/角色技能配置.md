# 角色技能配置

技能效果、范围、费用、动画与特效统一在 `Assets/ScriptableObjects/SkillPackListSO.asset` 编辑。每条技能有稳定 `skillId`，技能改名不影响引用；同名而效果不同的历史技能保留为独立条目。

`PieceData` 仅配置技能库、近战技能、远程技能和初始主动技能 ID，Inspector 提供技能下拉选择。旧的内嵌字段隐藏且已清空，仅作为历史数据迁移通道。专长仍使用原有专长配置库。

玩家 `Player.skills` 保存 `learned`（已学习）与 `equipped`（当前配置）ID。旧存档首次初始化继承角色默认技能；已有配置，包括主动清空的配置，不会被初始化或装备刷新覆盖。敌人每次初始化使用独立的默认配置。

运行时入口：

- `PieceController.LearnSkill(skillId, equip: false)`：学习技能，可选择立即配置；动作执行中允许单纯学习，但拒绝立即配置。学习费用、等级条件由调用方控制。
- `PieceController.ConfigureSkills(skillIds)`：原子替换整组配置，仅接受技能库中存在且已学习的技能；允许空列表，攻击动作中拒绝切换。
- `PieceController.RefreshConfiguredSkills()`：汇总存档配置与装备附加技能，刷新运行时 `availableSkills`，不修改共享 SO。学习或配置失败不会重建可用列表，配置成功后通知战斗界面更新。
- `Player.GetConfiguredSkills(pieceData)`：供角色面板等场景外功能读取配置。
- `SkillLoadoutState.Initialize/Learn/Configure/Resolve`：供未来升级、奖励与技能配置系统直接调用；状态随现有 Player 存档保存。

新增技能时在技能库添加条目，编辑器会分配 ID。复制技能产生重复 ID 时保留列表中首条定义的 ID，为后续副本分配新 ID。角色只通过下拉选择已有技能；不要复制整段技能到角色数据中。

历史资源迁移菜单：`Tools/技能配置/迁移角色技能到统一技能库`。迁移保留同名技能的独立参数，并在完成后标记角色库，重复执行不会新增重复条目。
