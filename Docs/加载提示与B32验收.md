# 加载提示与 B32 验收

2026-10-30 在 Unity 2021.3.23f1 的 PR4-2 隔离项目中执行。

## 使用与实现

- 默认目录为 `Assets/Resources/UI/LoadingTipCatalog.asset`，可在 Inspector 编辑标题及正文；也可为转场组件指定其他 `LoadingTipCatalogSO`。空正文不参与轮播。
- 加载界面默认每 6 秒切换；鼠标左键立即切换，连续点击至少间隔 0.5 秒。间隔均可在转场组件配置，使用不受游戏时间倍率影响的计时。长文本按可用高度分页，点击或自动轮播逐页前进。
- 显示内容只随加载生命周期创建和更新，不写入存档；转场结束、失败或组件停用时关闭提示。无预设加载面板时使用黑屏回退面板。
- 默认目录包括操作提示及根据现有目标类型配置整理的背景介绍，内容可继续由项目编辑。

## 验收范围

- 18 项检查通过，Unity 控制台无错误：包含默认目录、空/单条/多条、自动切换、点击冷却、长文分页和正文完整性、重复进入、停止后不再处理输入，以及实际 PR4-2 场景加载结束后的清理。
- 检查 1280×720 与 1920×1080 画面及长文边界；测试通过直接调用计时与点击处理路径验证，未模拟操作系统鼠标事件。失败路径的清理按代码检查，未纳入最终无错误运行；发行构建未验证。
- 测试脚本、夹具、截图和结果保存在 Git 忽略的 `tmp/LoadingTips/B32/`；场景及构建列表只在隔离副本中临时调整，验证后恢复。
