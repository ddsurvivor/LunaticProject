# B12 模因双槽界面与正式配置验收

## 使用入口

- 战斗中：当前可操作角色的行动菜单新增“模因装配”。选择槽位，再点击词条；可清空当前槽。整套配置确认后支付一次2 AP。
- 战外：角色页面右上角“模因装配”，确认免费；战斗进行中从角色页面进入时仍走战内校验，不允许免费绕过。
- 词条列表展示解锁状态，详情展示目标身体/标签、施加概率、识别门槛、反应限制及当前装备/角色/技能/插件来源。详情支持滚动；槽位草稿不影响“当前来源”。
- 取消、右键、Escape、控制权丢失、死亡及离开战斗均放弃草稿。重复词条、未解锁/无效词条、无变化、AP不足、外部控制及其他入口更新配置会拒绝确认。

## 解锁、存档与接口

正式目录不会默认赠送解锁。现有进度保留，旧档缺失/空字段以空槽及未解锁显示；打开、浏览、预览及取消不会修复或写回存档。

剧情新增`UNLOCKMEME(1001)`等指令，由`DataManager.TryUnlockMeme(id, out error)`调用现有永久解锁接口；成长/配方也可使用同一入口。无效和重复解锁不修改进度。存档仍沿用既有保存流程，装配及解锁保存在`Player.memeSlots`、`PLAYERPROFILE.memeProgress`，没有另建存档格式或改动配方经济。

`MemeLoadoutPanel`只持有独立草稿和打开时的槽位快照，确认调用`MemeService.TryEquipInBattle`或`MemeEquipment.TryEquipOutsideBattle`。其他入口改变槽位后拒绝旧草稿覆盖。战内扣AP后的散热/麻痹中断沿现有规则保留已扣AP，但不提交装配；重复确认不会重复支付。

界面以运行时uGUI接入现有Canvas，沿用原字体，未重建现有角色页或战斗菜单预制体。`ClickManager`和行动展示流程在装配弹窗期间等待，关闭后由原流程恢复菜单。角色页旧选中标记可能是Unity空对象，`UITabController`改为显式判空后访问原生接口，避免打开真实页面时报错。

现有正式技能库没有可直接映射的疫苗、更新、真影主动技能定义；本轮没有虚构技能费用、给普通回血添加解控或改变既有复活技能目标。指定治疗接口已在B10/B11验证，具体治疗资源和获取内容待相应技能/剧情定义确定后配置。状态图标与完整状态详情随B20；其他编号待验收项保持原状态。
