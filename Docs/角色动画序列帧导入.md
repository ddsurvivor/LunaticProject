# 角色动画序列帧导入

在棋子 `PieceDisplay` Inspector 点击“打开角色动画导入”，或选择棋子后打开 `Tools/角色动画/序列帧导入`。

1. 检查目标、素材文件夹与角色前缀。首次使用从当前绑定推断，后续配置按目标保存在本机 EditorPrefs。
2. 不同动作前缀可在“按动作覆盖前缀”中设置。例如成年绿默认 `PC02A`，移动覆盖为 `PC02`。移动同时支持 `move`、`run`，两套素材同时出现时需先整理，工具不会任选一套。
3. 默认保留原待机中的重复帧编排；需要使用完整的新待机素材时，取消“保留原待机编排”。
4. 点击“扫描预览”，查看每个动作的帧数变化、首末帧、未采用文件；“查看序列”可拖动帧滑块或播放预览。取消勾选的动作不会被修改。
5. 点击“一键导入并保存”。已有配置时也可直接点击此按钮完成扫描和导入。预制体资源及预制体编辑模式会保存，普通场景对象标记为待保存；场景预制体实例需打开源预制体后导入。

支持 `.png` / `.PNG`，文件位于所选目录的直接子级：

| 类型 | 示例 | 顺序 |
|---|---|---|
| 无编号首帧 | `PC02idle.png`、`PC02idle2.png` | 无编号首帧在最前 |
| 数字编号 | `PC02idle2.png`、`PC02idle10.png` | 按数字排序 |
| 四位帧号 | `PC02melee0000.png`、`PC02melee0001.png` | 从 0000 或已有首帧开始 |
| 旧技能格式 | `PC02skill1-1.png`、`PC02skill1-2.png` | 技能组 1，对应 index 0 |
| 新技能格式 | `PC02skill10000.png`、`PC02skill10001.png` | `skill1` + 四位帧号，对应 index 0 |

技能组编号支持 1–100；缺失组不压缩后续 `SkillPack.animationIndex`。无匹配动作保留原绑定；重复编号、同动作混用命名或非 Sprite / Single 图片会阻止对应选中动作导入。编号断档给出提示，但仍读取后续帧。`B` 版、空格副本和不匹配名称列入未采用文件。

纹理类型错误时可以显式修复为 Sprite / Single，保留原 PPU、轴心和滤镜。帧间 PPU、归一化轴心不同会提示，需在纹理 Inspector 核对。导入绑定支持撤销、重做；纹理设置修改后的重新导入不属于绑定撤销。

播放规则保持原样：普通动作 6 帧/秒、移动 12 帧/秒、闪避共 1 秒；近战、远程、技能在序列中点出手。增加帧数会延长动作和改变出手时刻。
