# LunaticProject 文档

Unity工程的开发与验收入口。开发分支为 `dev_feature`；根目录[AGENTS.md](../AGENTS.md)约定执行规范。

| 文档 | 用途 | 何时读取 |
| --- | --- | --- |
| [开发计划](开发计划.md) | 用户发布的任务、机制新增、问题修改及阶段完成条件 | 开始任务时，读取当前要执行的阶段 |
| [验收和结果](验收和结果.md) | 最近对话结果、阶段结论、待验收状态与证据入口 | 了解做了什么、实际验证到哪里 |
| [程序框架](程序框架.md) | 总体规范和模块用法索引 | 按任务定位相关模块，避免全量读取历史流水 |

文档维护：需求写入开发计划，实施完成后更新模块说明，对话结果写入验收和结果；README只维护路径指引，程序框架只维护规范和模块索引。详细汇报、截图、日志和旧原文收在 `tmp/Reports/`，由Git忽略。结果正文最多保留最近5批，较早记录收敛为阶段结论，未完成任务与待验收入口持续保留。
