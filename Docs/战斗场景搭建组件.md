# 战斗场景搭建组件

预制体目录：`Assets/Prefab/Battle/Authoring`。

把预制体拖进战斗场景，在对应脚本里修改尺寸。根节点的 Transform 只用于移动和绕 Y 轴旋转，缩放会被组件自动纠正。建议父节点保持单位缩放。参数在编辑器中修改后自动刷新，也可以点击 Odin 的「检查并刷新」按钮。

## 障碍物掩体

使用 `障碍物掩体.prefab`，在 `BattleObstacle` 中设置宽、高、深和图片。BoxCollider 与 NavMeshObstacle 自动同步，导航障碍开启 Carving；地面本身需要已有可行走 NavMesh。

「提供掩体」开启时接入现有 CaverSlot 掩体判定，可设置闪避与减伤数值；关闭后作为普通障碍物。点击「归位到 Y = 0 并刷新」会把根节点移回地面，并同步图片和碰撞体。

## 高层平台

使用 `高层平台.prefab`，在 `BattlePlatform` 中修改宽、深、平台高度、顶面图片和侧面图片。高度相对于根节点 Y；例如根节点 Y 为 0、高度为 3，平台顶面就在 Y = 3。

平台自动生成顶面的可行走 NavMesh，修改尺寸、高度或位置时替换旧导航，并同步实体碰撞和顶面、侧面图片。运行时启用组件也会生成导航，无需保存额外的导航资产。「导航已生成」可检查生成状态，默认 Agent Type ID 为 0，与现有棋子一致。

高低层之间的通行仍需按关卡设计放置现有 LadderArea 等连接设施。平台不会自动生成楼梯或跨层传送点。

## 角色出生区域与整备部署

使用 `角色出生区域.prefab`，在 `BattleDeploymentArea` 中设置矩形宽、深。支持绕 Y 轴旋转，同一战斗场景可以放置多片区域。绿色范围只作显示，不阻挡物理碰撞和导航。区域需要覆盖已有的可行走 NavMesh；放在高台上时，将根节点 Y 设置为平台顶面高度。

场景存在启用的出生区域时，BattleManager 在原有开战流程前进入部署阶段：

1. 保留己方可控制棋子的合法站位；其他棋子尝试在各区域内寻找空位。
2. 左键选择己方棋子，再点击任意绿色区域调整位置；右键或 Esc 取消选择。
3. 棋子整个占地必须在同一片区域内，不能与其他棋子或实体障碍重叠，不能跳到其他楼层。部署不消耗行动力。
4. 点击「开始战斗」后检查所有可控制棋子的站位。检查通过后隐藏区域，继续原有开场与回合流程；空间不足时会提示调整，不能直接开战。

这里调整的是现有队伍棋子的站位，不负责创建队伍成员。没有出生区域的旧场景沿用原有开战流程。

## 维护与验证

- `Tools > 战斗搭建 > 生成三个搭建预制体`：重新生成三个默认预制体，会覆盖该目录下对应预制体的自定义配置。
- `Tests > Battle > Validate Authoring Prefabs`：在临时场景执行导航、碰撞和区域校验；运行前保存当前场景。
- 当前已通过 Unity 2021.3.23f1 后台的 20 项组件校验，以及开战状态机的 15 项回归测试。后台校验不包含实际游戏画面的鼠标操作验收。
