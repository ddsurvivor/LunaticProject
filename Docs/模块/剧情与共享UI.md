# 剧情与共享 UI

战斗对话沿用AVG阅读器，通过战斗适配管理暂停、真实时间与完成回调。避免把战斗专用预制体覆盖同步到通用AVG源模板。

## 剧情跳过与音频清理

批量跳过先通过 `AudioManager.StopAll()` 停止全部音效并取消待加载音效；跳过过程中正文、选项提示及章节音效统一经 `PlayStorySound` 抑制，包括递归 NEXT 跳转。变量、奖励、分支与音乐指令继续执行；跳过在选项或控制行停止后，正常显示内容恢复音效。异常或提前离开都会释放跳过状态。

`StopAll()` 只取消音效请求，不取消BGM加载；音乐由 `停止音乐()` 独立取消。`播放音效(name,0)` 先取消该名称尚未完成的旧请求，已开始的循环播完当前一遍，尚未开始则改为单次，避免异步循环请求在结束指令之后重新启动。

返回主菜单仍经 `GM.LoadScene` → `TransitionRoutine` → `BeginSceneTransition`，同时停止音乐和音效并阻止转场期间播放。新场景加载后解除播放锁，但旧异步请求因版本过期不能恢复。B59的14项受控回归及主程序集编译通过，尚未替代真实AVG试听和Player验收，证据入口见[验收和结果](../验收和结果.md)。

对话页面的所有关闭出口通过 `StopReaderAudio()` 同时停止循环BGM和全部音效、取消待加载请求，包括 `EndReadingStory`、开始淡出、立即隐藏、`OnDisable` 和 `OnDestroy`。同一次关闭只执行一次清理，避免关闭动画结束后的禁用误停新页面音乐；重新显示或开始新剧本时恢复播放资格。关闭后的SOUND/MUSIC及推进不再执行播放。Game Over显式结束并隐藏剧情，移除延迟重播失败分支；无显式END的剧本在读到末尾后再次推进时同样结束并隐藏。临时隐藏仍不标记剧情完成。追加15项生命周期受控检查通过，真实试听待验收。

音效停止版本与音乐版本独立；加载成功后替换已播放循环时只清理活动音源，不取消同名后续请求。AudioManager销毁时先停止全部音源，再释放缓存句柄。手动推进入口允许末尾交给Next执行关闭，已关闭状态不消费后续输入。SOUND/MUSIC按指令名精确分发，音频名称及STOP参数去除首尾空白，STOP忽略大小写，非法循环参数不抛转换异常；MUSIC(name,1)继续兼容旧剧本。488条现有音频指令的格式和源音频引用检查通过；修正范围与验证边界见[本批结果](../验收和结果.md)。

## 共享视觉模块

### 交付位置

- `Assets/Art/UI/AvgCommon`：8 张独立 PNG，保留透明背景。复制自现有 AVG UI 素材，不改动原图及其导入配置。
- `Assets/Prefab/UI/AvgCommon`：Panel、Header、Button、Separator、Track、Portrait 六个通用 uGUI 组件。
- `Assets/Resources/UI/SpeedTimeline.prefab`：可直接编辑的完整速度条。
- `Artifacts/UI/SpeedTimelinePreview.png`：Unity 实际渲染的组件预览。

### 素材与九宫格

| 素材 | AVG 来源 | Border：左/下/右/上 |
|---|---|---|
| PanelCut | 返回开始菜单/切角面板 | 28/28/28/28 |
| HeaderCut | 返回开始菜单/标题栏 | 26/26/26/26 |
| ButtonNormal | 对话框/选项 | 40/12/28/12 |
| ButtonSelected | 对话框/选项选中 | 40/12/28/12 |

| Accent | 返回开始菜单/标题强调 | 0，普通图像 |

四种面板/按钮素材通过 Unity TextureImporter 设置九宫格；对应 Image 使用 Sliced。按 RectTransform 尺寸调整组件，避免直接缩放整个对象。按钮包含正常、高亮、按下和选中状态，业务点击事件留给使用者绑定。

### 速度条接入

`UIManager.speedTimelinePrefab` 可显式指定预制体；为空时自动加载 `Resources/UI/SpeedTimeline`。战斗开始后实例化到现有根 Canvas 顶部中央，不新增 Canvas 或 EventSystem。

`SpeedTimelineUI` 的 Track、Marker Template、Lane Offset 可在 Inspector 中调整。角色头像从右向左移动；青色/红色底线标识敌我，金色外框突出当前行动者。B82起仅头像根背景打开Raycast Target接收选中/聚焦，头像图像、裁切和装饰文字仍关闭射线；队列和当前行动者强调规则保留。

PortraitTemplate 默认隐藏，只作为实例模板，不会在实际战斗中多显示一个头像。预览图中的角色位置与头像是展示样例；实际战斗读取当前棋子、速度进度和角色头像配置。

### 重建与验证

重建与校验脚本已迁入本地临时目录 `tmp/Assets/Scripts/Editor/SpeedTimelinePrefabBuilder.cs`，不再随仓库提交，也不会默认加载到 Unity。需要重建时按临时测试方式加载并执行，完成后清理入口；测试报告存放在 `tmp/Results/`。

重建会覆盖专用输出目录中的 PNG 和预制体，并校验引用、切片、射线遮挡及组件预览；手动调整后的预制体请不要直接重建覆盖。

已完成 Unity 2021 批处理编译、导入、预制体引用与切片校验和离屏视觉检查；未在实际战斗 Play Mode 中完整运行。

## 战斗对话接入

### 战前剧情与战斗HUD（B80）

开场扫视/教程结束后进入`OpeningDialogue`阶段，触发本关`BattleStart`剧情；阅读器完全关闭后才显示开战演出并启动普通速度回合。空剧本、未配置对话管理器及抑制外部表现的自动测试立即经同一完成入口继续。随机种子初始化保留原先在剧情触发前的位置。重复关闭、取消/重开或旧场景回调不能重复开战或影响新场景。

`UIManager.OpeningDialogue`仅用CanvasGroup遮住角色信息/行动/状态、头顶、速度条、聚能、战斗日志/通知及快进等战斗HUD，不关闭宿主Canvas、阅读器或业务组件。保存并恢复每个组的原透明度、交互/射线及启用状态，不强制激活原本关闭的面板；子组忽略父级时仍遮蔽，开场期间新增HUD在初始化及LateUpdate纳入遮罩。取消或UI停用释放遮罩，UI重启时按当前开场阶段重新接管。

剧情正文、骰子和设置继续使用原入口；开场剧情设置通过阅读器专用入口打开既有设置窗口，关闭设置不释放阅读器的暂停。战斗菜单热键在遮罩期间被阻止。部署界面不属于此遮罩，战中剧情沿用原显示行为。41项隔离Play Mode检查及双程序集编译通过，截图与夹具边界见结果页；真实剧本跳过、完整关卡及Player仍待用户验收。

### 正式实现

- `Assets/Prefab/Battle/BattleScene.prefab` 的旧阅读器已换为与AVG相同的 `Assets/Prefab/UI/剧本阅读器新.prefab` 嵌套实例，保留对话框、按钮、前景正文、CG、骰子及共享正文预制体的连接；复制AVG实际实例的布局覆盖。13个场景的实际 `BattleScene.UM.logSystem` 和适配引用均有效，因此没有重存任何场景。
- AVG场景、新版阅读器源资产、正文/选项源资产及其他既有预制体保持原文件内容。保留旧阅读器资产供其他引用使用，没有删除资源；没有改变剧本名、触发列表、关卡数值或Build Settings。
- 新增 `BattleDialogueView`，阅读器启用时独立持有战斗暂停，隐藏/禁用时仅释放自己的持有者；设置窗口的暂停不受影响。阅读器通过正常关闭入口完全隐藏后，一次通知本场对话管理器；禁用/卸载不继续旧场景回调。
- `UIManager.StartLog` 统一分发到对话管理器，再由内部显示入口打开阅读器并清空旧UI选中项。重复的完成通知不重复调用回调，管理器禁用清理旧回调；重复聚能就绪提示直接完成调用方，不阻塞后续。
- 战斗适配器启用阅读器的真实时间计时，覆盖逐字、自动/快进、背景/CG/震动与骰子，避免世界暂停使对话停止。AVG阅读器默认仍使用原时间方式，关闭淡出仍用其已有真实时间逻辑。
- 底部“设置”复用本场已有设置窗口。AVG的“记录”实际上打开存档页，本战斗实例禁用该按钮并清空其外部事件，保留原布局；没有增加战斗存档旁路，也没有恢复B35其他面板迁移。
