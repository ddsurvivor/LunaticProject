# 角色技能配置

## 技能数据与装配

技能效果、范围、费用、动画与特效统一在 `Assets/ScriptableObjects/SkillPackListSO.asset` 编辑。每条技能有稳定 `skillId`，技能改名不影响引用；同名而效果不同的历史技能保留为独立条目。

`PieceData` 仅配置技能库、近战技能、远程技能和初始主动技能 ID，Inspector 提供技能下拉选择。旧的内嵌字段隐藏且已清空，仅作为历史数据迁移通道。专长仍使用原有专长配置库。

玩家 `Player.skills` 保存 `learned`（已学习）与 `equipped`（当前配置）ID。旧存档首次初始化继承角色默认技能；已有配置，包括主动清空的配置，不会被初始化或装备刷新覆盖。敌人每次初始化使用独立的默认配置。

运行时入口：

- `PieceController.LearnSkill(skillId, equip: false)`：学习技能，可选择立即配置；动作执行中允许单纯学习，但拒绝立即配置。学习费用、等级条件由调用方控制。
- `PieceController.ConfigureSkills(skillIds)`：原子替换整组配置，仅接受技能库中存在且已学习的技能；允许空列表，攻击动作中拒绝切换。
- `PieceController.RefreshConfiguredSkills()`：汇总存档配置与装备附加技能，刷新运行时 `availableSkills`，不修改共享 SO。学习或配置失败不会重建可用列表，配置成功后通知战斗界面更新。
- `Player.GetConfiguredSkills(pieceData)`：供角色面板等场景外功能读取配置。
- `SkillLoadoutState.Initialize/Learn/Configure/Resolve`：供未来升级、奖励与技能配置系统直接调用；状态随现有 Player 存档保存。

新增技能时在技能库添加条目，编辑器会分配 ID。复制技能产生重复 ID 时保留列表中首条定义的 ID，为后续副本分配新 ID。角色只通过下拉选择已有技能；不要复制整段技能到角色数据中。

历史资源迁移工具`CharacterSkillCatalogMigration`的Tools菜单已在B63撤下，实现暂留并标记后续删除。其迁移逻辑保留同名技能的独立参数，完成后标记角色库，不自动重复创建；此描述不是当前菜单操作入口。

## 动画时序、出手与弹道（B61/B62/B64）

B74（2026-11-24）覆盖下文旧的统一12 FPS规则：在 `Assets/Resources/BattleAnimationSettings.asset` 的Inspector中设置 `Normal Frames Per Second`（默认6，适用于待机、移动、近战、射击、闪避、受击和死亡）及 `Skill Frames Per Second`（默认12，仅Skill动作）。正式播放、导入预览及出手调节器使用同一设置；单图正数停留秒数优先，0或缺项使用对应动作默认帧率。帧模式的出手时刻随速度变化，旧秒模式保持绝对秒数；修改速度后应检查已调校的攻击和出手表现。播放中动作保留启动时的时长快照，新动作使用最新设置。全局配置缺失或数值无效时回退6/12。

棋子序列以`PieceDisplay.FramesPerSecond = 12`为默认，每帧约83.33毫秒；`ActionReleaseTiming.frameDurations`允许逐图覆盖停留秒数，0/缺项使用默认值，不补图或复制图片。两帧射击可将第1张设为0.20秒、第2张0.35秒，并选择第2帧发射，得到0.55秒动作和0.20秒发射点；这些数值是调节示例，没有批量写入角色资产。多帧素材可全部保留默认。正式播放器、动画导入预览和出手工具共用`PieceAnimationTimeline`的累计取帧规则，不改变游戏渲染帧率或棋子逻辑移动速度。

入口：`Tools/角色动画/技能出手调节`，或选中棋子后点击PieceDisplay Inspector的“打开技能出手调节”。选取角色和技能库/技能，工具根据正式PieceData识别近战、远程或主动技能入口；也可手动选择Attack、Shoot、Skill及动画索引。场景预览只创建SpriteRenderer和PieceDisplay，不运行棋子的费用、伤害、回合或音频逻辑。

支持循环/单次、暂停、逐帧、时间轴、慢放、循环间隔、逐图停留秒数及当前帧设为出手点。帧号从1开始，第N帧出手秒数是前N−1张图时长之和，全部默认时才等于(N−1)/12。新设置默认按帧；已有秒模式保留绝对秒数，超出新动画末帧开始时会提示并阻止保存，需显式校准，不静默改写源配置。出手时Scene视图显示黄色圆圈和文字；有弹道技能还显示示意飞行点和预计到达时间，需开启Gizmos观察。这个飞行点只是时序预览，不创建正式子弹/伤害。关闭窗口、脚本重载和进入运行模式会销毁预览对象。

`PieceDisplay.releaseTimings`保存角色的动作/动画默认值和稳定skillId覆盖，解析优先级为角色技能覆盖→角色动画默认→序列中点；配置在动作开始时快照。调整即时作用于预览草稿，点击保存才提交，支持Unity Undo/Redo、还原草稿与删除当前覆盖。选择Project中的预制体时直接保存该资产；选择场景实例时只记录该实例覆盖并标记场景待保存，不自动改写来源预制体，需要共享配置时使用Inspector的Overrides应用。

一个动作一个出手点。无弹道（`bulletVFXType == NONE`）在出手时直接进入命中/受击链路；有弹道在发射帧生成子弹，按实际三维距离/速度飞行，到达后才进入命中/受击链路，未命中/闪避仍沿原规则。角色动画结束不代表子弹到达，正式动作会继续等待弹道及反应。缺失弹道、无效速度或中断不伪造命中，零距离可同刻到达；低帧率跨过出手点只触发一次。

技能库的`SkillPack.projectileSpeed`为世界单位/游戏秒，0代表兼容旧资源的默认20，正数显式覆盖；负数/NaN/无穷拒绝发射。调节窗口对有弹道技能提供速度和预览距离，保存速度会改所选共享技能库（影响共用该技能的角色），窗口仅允许保存有限正速度；角色出手点/停留时长仍属于PieceDisplay。`isDelaySkill`仍为延期结算玩法开关，施放音效保持既有启动时点。
