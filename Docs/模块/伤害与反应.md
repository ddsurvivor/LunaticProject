# 伤害、行动上下文与反应

公式与已确认规则见[战斗规则](战斗规则.md)。实现边界与待补验项见[开发计划](../开发计划.md)，不要将预览区间当作整条连锁最终结果。

## 伤害来源与异步接口

更新：2026-10-29，B08。现行伤害、识别、掩体及计时规则沿用[B07兼容基线](战斗规则.md)，本次不采用新玩法数值。

### 入口与来源

所有现有伤害仍由UnitAttrCenter提交生命变化；新增带BattleDamageSource的TakeDamage重载。旧单参数调用保持可用，来源为Unknown，不重复扣血。自定义扩展应显式提供来源。

| 当前入口 | 来源分类 | 行动与归属 |
| --- | --- | --- |
| DamageManager.ResolveSkillTarget | Skill | 攻击者、技能及显式或当前行动；多目标PieceSkill共用行动，各段保留同一根ID |
| 普通桶/电浆桶/自爆召唤物 | Skill | 沿用原PieceSkill路径，施法者为环境对象；普通桶与电浆延迟回调捕获触发时根行动。原归属和死亡施法许可不变 |
| BuffManager回合持续伤害 | Periodic | 旧BuffState没有施加者/原始行动信息，因此不猜测施加者；本次持续结算有独立ID。完整状态来源传播随B10处理 |
| 旧行动前异常伤害 | ActionEffect | 标记承受异常并发起该行动的角色，不将其当作已知的状态施加者 |
| 击退碰撞 | Collision | 安排位移时捕获施法者与根行动，回调不读取届时其他角色的行动 |
| SelfExplosionEffect | SelfDamage | 保留自损100及原类型，当前行动内带入施法者 |
| 插件蛛丝直伤 | Component | 插件原有固定伤害和被动通知顺序不变，附攻击者/技能与当前根行动 |

爆炸物Skill分类不表示其伤害是单体，也不自动授予免疫；精确范围标签和免疫规则属于B14。召唤物自主探索造成的攻击建立自己的行动，不自动把多回合后的伤害归给召唤者。

### 实际生命结果与事件

带来源的TakeDamage返回BattleDamageResult，包含Target、Source、Requested、HealthBefore、HealthAfter、HpLoss、Killed、Ignored。结果在生命回调和死亡逻辑前固定，后续被动治疗等不会改写该段快照。伤害公式输出与DamageInfo继续使用原有数值，不把展示/聚能/碰撞基数静默改为实际掉血。

每次有效提交完成后，UnitAttrCenter.DamageApplied发送一次结果；零伤害有事件且HpLoss为0，保留受击表现。死亡目标与负伤害被忽略且不发事件；致死后原段循环停止，不重复通知死亡。屏障全吸收在DamageManager内部结束，不调用TakeDamage，也不发生命提交事件。DamageManager.Settlement.DamageResults保留本次实际进入生命提交的各段结果，屏障吸收不在其中。

现有NotifyHpChanged、NotifyTakeDamage、NotifyKillEnemy和受击回调仍按原有入口执行；本次没有把DOT/碰撞等强行接到旧技能被动通知上，避免扩大现行触发范围。新规则若需要统一观察各类实际掉血，应订阅DamageApplied，而不是同时把它与旧NotifyTakeDamage当成两次伤害。观察者不应再次扣除已提交伤害，销毁或换场景时自行解除订阅。

本轮不提供未命中/屏障吸收的完整战果日志，也不改变伤害事件重入、状态解除或反应优先级；这些需后续结算/反应服务处理。

### 根行动及异步边界

BattleActionContext提供进程内单调递增ActionId、RootActionId、Actor、Skill和IsReaction；不作为持久化技能ID或存档ID，不实现撤销快照。新子行动继承当前或显式父行动的RootActionId。该ID只用于关联，不自动去重伤害，也不代替B09的反应上限和根行动去重键。

MemeActionContext继续负责原有来源合并和尝试去重，并持有Action。旧调用创建的空Action只在真实PieceSkill入口通过EnsureAction补齐一次，检定等待恢复时仍复用。模因预览显式使用isPreview，不分配行动身份。

Enter作用域只用于同步主线程结算；using退出或异常时恢复父上下文。不得跨yield或动画等待保持全局Current。弹道沿用CombatActionRoutine已有MemeActionContext，识别等待沿用已有上下文；延迟碰撞、延时技能、夹击及桶引信各自捕获并在同步回调中恢复根行动。新建异步扩展同样必须显式捕获，不能在回调触发时直接读取Current来推断原行动。

费用提交时机、延时技能触发时点、桶引信、AOE目标顺序、夹击顺序和状态持续均保持原有实现。本轮不修复或重写B09/B15/B19的生命周期问题。

### 随机源与恢复

BattleRandom统一暴露整数/浮点Range、Value及CaptureState/RestoreState。伤害暗骰、识别、模因、旧Buff概率、插件、战斗被动、敌人AI采样/选择、楼梯接近点和队伍面板随机生命值已改用该入口。暗骰仍为四次1–6采样，现有概率比较符、边界和短路条件保持原状。

后端仍是UnityEngine.Random，全局状态与自动战斗宿主现有InitState及退出恢复兼容。移除了DamageCalculator单独的System.Random，因此旧版本同种子结果不保证逐次一致；骰子分布及B07公式保持不变。表现噪声UIPanel、轮廓采样ObstructionOutline、场景转场图选择及剧情骰子仍直接使用Unity随机，它们也共享同一底层序列。

CaptureState本身不消费随机数；直接伤害预览穷举原有分支，不调用BattleRandom，不产生生命事件或行动ID。RestoreState会同时回滚共用Unity序列的表现/剧情调用，应在稳定边界使用。当前没有独立的战斗随机流、跨版本回放保证或完整场景快照；若未来要求隔离，需连同表现、剧情和自动战斗一起设计迁移。

## 反应队列

### 本次实现范围

B09 在已确认的现行规则上整理击退、夹击和警戒时序，不修改伤害公式、碰撞基数、识别门槛或模因的反应开关。核心实现位于 `BattleManager.Reactions.cs`，复用 B08 的 `BattleActionContext`。

- 命中时登记夹击检查，等待原攻击、受击、识别结算和所有在途击退结束，再按实际落点选择最近的有效队友。碰撞扣血先于夹击选择。沿用最近一名队友、`ableStrick` 和夹击期间不再派生夹击的限制。
- 同一根行动的夹击检查按攻击者/目标去重，实际夹击再按队友/目标去重；警戒按警戒者/目标去重。异步行动持有同一根的预算，出队不返还次数；记录随根上下文释放，不建立跨战斗的永久索引。
- `maxReactionDepth` 默认 8，`maxReactionEvents` 默认 64，可在 BattleManager Inspector 调整，最小为 1。后者同时约束每根累计接纳事件与全局等待队列长度。夹击资格检查也占一个事件；上限用于终止失控链，不新增伤害倍率。
- 队列逐项执行，重查存活、启用、阵营、敌人激活、指令是否仍有效、攻击配置、认知保护及必要资源。夹击检查眩晕但不新增 `OnAction` 自损触发；警戒保留原 `BuffManager.OnAction` 行为。父上下文只在同步推进结算时进入，不跨帧持有。
- 警戒在确认时快照扇形方向，检查每段实际移动的水平线段与环形扇区是否相交；保留原半径、角度和 1 米内圈。移动结束前补查最后一段，两个端点均在区外也能捕获穿越。被捕获的单体攻击不因目标随后离开而丢失；敌方范围攻击仍沿现有范围查询，不扩展命中名单。
- 玩家与敌人警戒都在成功发动攻击后消耗 `maxTriggerCount`，耗尽后解除；排队期间不重复提交，未成功出手不消耗次数。按阵营清理警戒时，不再直接丢弃另一阵营的记录。
- 击退纳入共同表现锁。同一棋子再次击退会取消旧位移，取消时不补碰撞；保留原 Agent 启用状态。胜负、退出、禁用和场景卸载清空队列、警戒跟踪及本场击退，同时取消队列当前持有的反应攻击与弹道，用版本防止旧回调补发碰撞。
- `PieceController.GetRange` 在相应普攻缺失时返回 0，避免 AI 的射程读取空引用；不替角色生成或配置技能。

## 碰撞规则

### 问题与修改

旧配置击退读取 `HitBackEffect.hitBackDamage` 固定值，聚能默认击退使用展示伤害之和乘 0.4，二者均不能代表实际生命损失。过量伤害及屏障吸收时会产生错误基数。

现在从 `DamageManager.Settlement.DamageResults` 汇总本次直接伤害各段 `HpLoss`，传入配置击退和聚能默认击退。快照不包含过量伤害、被动派生伤害或屏障吸收；聚能延期回调携带该数值，不在释放时读取剩余生命。原击退距离公式和导航规则保持。

`BattleCollisionImpact` 使用整数运算计算 `floor(actualHealthLoss × 0.4)`，避免浮点舍入与乘算溢出；每次击退只消费一次碰撞，消费标记先于生命回调。路径在首次碰撞处停止，移动者及首个被撞棋子各结算一次，撞墙仅结算移动者。重复参与者、重复/重入提交不重复扣血，零基数不发送伤害事件。使用直接生命提交，保留 Collision 来源与根行动，不重新执行技能或派生击退。

旧 `hitBackDamage` 字段为资产兼容保留并隐藏，不再参与计算；未重序列化技能库、棋子数据、预制体或场景。

## 掩体与高低差

日期：2026-10-30。B25 已按用户要求标记为跳过；B18 与计划指定随项完成的 B27 已完成当前共享规则及 PR4-2 受控验收。

### 已确认规则与实现

- 掩体 1–3 级分别减少基础攻击 20%/35%/50%，各级统一增加 20 个百分点闪避。全局数值及保护距离在 `GameConstSO` 配置，保护距离默认 2；场景 `CaverSlot` / `BattleObstacle` 配置等级，旧场景缺省为一级。保留原伤害公式中掩体先于护甲、暗骰及后续倍率的顺序，原必中特例保持原义。
- `BattleCoverQuery.Find` 按攻击者与目标脚点上方 1.2 的连线检查实体碰撞体，目标脚点至该命中碰撞体最近实体表面的距离不得超过保护距离。支持子碰撞体；多掩体取最高等级一次，同级稳定选择，不按射线返回顺序叠加。查询不依赖 `CurCaverSlot`、槽位是否已满或相机方向。
- 纯墙体、触发器、失效碰撞体、关闭的掩体和 `providesCover=false` 的纯障碍不授予保护。只识别显式掩体组件；不新增尚未定稿的通用墙体禁射规则。现有“弱防御射手避开掩体”的策略偏好改用同一查询，不把它解释为所有角色都禁止射击掩体后的目标。
- 槽位兼容接口不再额外添加 Shield/Conceal；非掩体来源的同名 Buff 继续按原规则生效。移除移动到达时仅凭附近槽位显示保护的旧分支，避免其与实际射线判定不一致。
- 掩体不新增完全挡伤判定，不独立阻挡状态、Buff 或击退。纯状态技能不因掩体降低命中；含攻击的技能继续遵守普通未命中与屏障效果门槛，命中后仍正常施加状态/击退。

### 高打低与查询统一

用户在本次明确回复“至少高出 1 个世界单位才生效”。实现采用大于等于 1 的边界，高差门槛在 `GameConstSO` 配置，默认 1；`layerSkill` 仍单独使用原来的 0.1 同层容差，两者不混用。

`BattleRangeRules` 统一玩家瞄准、确认命令、AI 合法性/落点/范围比较和只读查询：仅高打低的远程定点施放距离乘三，多层不继续累乘；同高、低打高、近战、支援保持基础距离。距离按既有玩家选点的水平面语义统一，高度由独立规则处理。

新增 `SkillReachKind.Auto/Melee/Ranged` 配置：显式标记优先；Auto 对旧内容依次按普攻引用或稳定 ID、已有敌人技能用途、相对近战射程兼容判断。保留旧技能资产，未批量改写或重序列化。含范围的道具与技能共用同一施放流程。

Circle 和 Grenade 可扩展选点距离，Grenade 的爆炸半径保持原值；以自身为中心的 Nova、Fan 和 Arc 几何尺寸均不扩大。跨层选点保留真实目标高度，鼠标读取实际棋子/地面高度；直接目标还须处于共享射程内，不再借单体选取小球越过最大射程。状态、层高、阵营及其他既有目标条件继续由 `SkillTargeting` 过滤。

范围边界、高亮与确认共用最终选点。正式结算位置改读不含图形离地偏移的 `SelectionPosition`，避免临界高差和 AOE 因准星抬高而与预览不同。AI 在当前层已有合法攻击时不先强制寻找楼梯，保留原近战限定与策略偏好。

## 战果预览

更新：2026-11-06。分支：`dev_feature`。用户确认本轮范围：直接伤害区间与命中率、掩体影响、预计击退落点、首个潜在碰撞及夹击候选；附带结果标明条件，不并入保证伤害，不模拟无限连锁。开发完成，状态为待验收；按用户要求不展开专项验收任务。

### 玩家可见行为

- 普通瞄准过程中，鼠标悬停在当前范围选中的有效棋子上，屏幕右侧显示一张共享战果提示；非当前瞄准目标不显示，不为每个棋子增加头顶大面板。
- 命中率、直接伤害区间沿用 `DamageManager.PreviewSkill`，与原伤害/护盾预览共用公式。掩体存在时显示等级及已计入的减伤。附带提示不计入直接伤害数字和头顶血条。
- 击退显示当前场景预计距离，并以浅蓝线及末端短线标记落点。显式单次击退使用其配置距离；聚能自动击退使用直接伤害上界分支并标注，不称为随机结果的保证落点。多次击退不预测最终落点或完整连锁。
- 首次潜在障碍区分棋子与墙体/地形边界；显示实际生命损失×40%的碰撞基数规则，撞棋子双方分别结算、撞墙仅移动者结算。不是最终碰撞掉血保证值。
- 夹击候选按预计落点查询，仍须命中、目标存活、效果未拦截、实际落点复核及实战反应资格检查。距离随随机伤害变化、模因/被动及其他单位后续变化可能改变结果，不计算夹击伤害总和或无限连锁。
- 移开鼠标、取消瞄准、聚能选人、进入动作表现或禁用控制器会隐藏/清理提示。提示图片和文字不接受射线，不阻挡世界点击；同目标每 0.15 秒更新，换目标立即更新。

### 实现与手调

`BattleManager.QueryKnockback` 提取原 NavMesh 截断、地面/棋子查询、Y 轴锁定逻辑，实战击退与预览共用；`FindFlankPartner` 复用原稳定注册次序、关系、距离与夹击资格查询，实战仍保留原根行动去重、状态复验与出手流程。查询不改 Transform、导航代理、资源或反应队列；删除已无调用的旧距离辅助函数。

共享模板为 `Assets/Resources/UI/BattleOutcomePreview.prefab`，沿用 AVG Panel 连接，文字、字号、宽高及屏幕偏移可在预制体手调。`Tools/Battle UI/Create Outcome Preview If Missing` 仅创建缺失资源，不覆盖后续布局。落点线是提示实例拥有的视觉对象与材质，随提示隐藏，销毁时释放材质。`RangeUI.PreviewSkill` 仅暴露当前瞄准技能的只读引用，取消范围时自然失效。

### 自爆与异步约束

- 自爆目标收集复用 `EnemyExplosiveTargets.CollectTargets`，支持子碰撞体查找父棋子、同棋子多个碰撞体去重及排除自身；向正式技能入口传入真实爆炸中心。
- 移动开始时捕获根行动，抵达时恢复同步作用域；自爆排队显式提供包含施法者和技能的派生上下文，释放时不借用其他角色的根行动。
- 已触发自爆使用 `WithDeadCaster()` 的临时技能副本，允许释放前死亡的施法者结算；原技能资产保持原规则。失活或重新 Init 的对象仍由世界效果队列的既有生命期校验剔除。
- 在途移动不在世界效果队列内，新增行动版本、双方 Init 版本、组件启用状态、施法者存活及战斗归属校验。目标死亡、失活、复用、改变归属、不可选中或离开触发范围时安全结束。
- 在途行动及已排队自爆拒绝重复 AI 请求；重复抵达与延期释放不再重复结算旧阵营回合的 Buff 持续时间。速度回合继续由正式调度器结算。
- 移动执行失败时停止移动动画并结束行动；缺少主相机时跳过空间音效，保留伤害、特效和回收。

### 召唤登记与复用

- `BattleManager.RegisterSummon` 唯一登记已初始化且激活的棋子，清理空引用与同对象重复项；重复登记保留原顺序，不改变同刻行动的稳定注册次序。
- 棋子保存当前召唤归属；停用、销毁和再次 `Init` 时撤销旧登记，移除同对象的全部旧条目。归属转移先从旧管理器移除；旧场景清理不能撤销新管理器的归属。
- 管理器禁用时按快照清空登记。死亡开始时不直接移除，保留尚在播放或延期结算的死亡表现，直至实际回收/停用。
- 旧召唤行动循环改为对象与 `BattleLifeVersion` 快照；每次行动前复查激活、登记及生命版本，避免列表变化导致迭代异常，或旧快照驱动复用后的新生命。
- 召唤入口先验证棋子 ID 配置；无效数据不再套用预制体回退数据。生成物体缺少棋子组件、初始化后场景改变或登记失败时回收本次物体。没有改动爆炸数值、AI策略、场景或预制体。
