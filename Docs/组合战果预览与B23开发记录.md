# 组合战果预览与 B23 开发记录

更新：2026-11-06。分支：`dev_feature`。用户确认本轮范围：直接伤害区间与命中率、掩体影响、预计击退落点、首个潜在碰撞及夹击候选；附带结果标明条件，不并入保证伤害，不模拟无限连锁。开发完成，状态为待验收；按用户要求不展开专项验收任务。

## 玩家可见行为

- 普通瞄准过程中，鼠标悬停在当前范围选中的有效棋子上，屏幕右侧显示一张共享战果提示；非当前瞄准目标不显示，不为每个棋子增加头顶大面板。
- 命中率、直接伤害区间沿用 `DamageManager.PreviewSkill`，与原伤害/护盾预览共用公式。掩体存在时显示等级及已计入的减伤。附带提示不计入直接伤害数字和头顶血条。
- 击退显示当前场景预计距离，并以浅蓝线及末端短线标记落点。显式单次击退使用其配置距离；聚能自动击退使用直接伤害上界分支并标注，不称为随机结果的保证落点。多次击退不预测最终落点或完整连锁。
- 首次潜在障碍区分棋子与墙体/地形边界；显示实际生命损失×40%的碰撞基数规则，撞棋子双方分别结算、撞墙仅移动者结算。不是最终碰撞掉血保证值。
- 夹击候选按预计落点查询，仍须命中、目标存活、效果未拦截、实际落点复核及实战反应资格检查。距离随随机伤害变化、模因/被动及其他单位后续变化可能改变结果，不计算夹击伤害总和或无限连锁。
- 移开鼠标、取消瞄准、聚能选人、进入动作表现或禁用控制器会隐藏/清理提示。提示图片和文字不接受射线，不阻挡世界点击；同目标每 0.15 秒更新，换目标立即更新。

## 实现与手调

`BattleManager.QueryKnockback` 提取原 NavMesh 截断、地面/棋子查询、Y 轴锁定逻辑，实战击退与预览共用；`FindFlankPartner` 复用原稳定注册次序、关系、距离与夹击资格查询，实战仍保留原根行动去重、状态复验与出手流程。查询不改 Transform、导航代理、资源或反应队列；删除已无调用的旧距离辅助函数。

共享模板为 `Assets/Resources/UI/BattleOutcomePreview.prefab`，沿用 AVG Panel 连接，文字、字号、宽高及屏幕偏移可在预制体手调。`Tools/Battle UI/Create Outcome Preview If Missing` 仅创建缺失资源，不覆盖后续布局。落点线是提示实例拥有的视觉对象与材质，随提示隐藏，销毁时释放材质。`RangeUI.PreviewSkill` 仅暴露当前瞄准技能的只读引用，取消范围时自然失效。

## 开发检查

- Unity 2021.3.23f1、PR4-2 隔离副本最终 **24 项通过、错误 0、65 帧**。包括开放路径落点、真实击退终点一致、棋子首次碰撞及实际碰撞伤害、墙体、不能移动、预计落点夹击/超距/资格耗尽、重复查询只读、共享悬停接入、移出/取消隐藏、非交互图形与落点线。
- 重复查询检查生命、AP、能量、聚能、夹击资格、位置、随机状态、延期事件及受击计数不变。UI 调用前后也做相同快照对照。
- 业务与编辑器程序集编译、差异检查通过。1920×1080 和 1280×720 截图已检查；画面使用临时测试区域和人工相机，不能冒充原关卡自然战斗截图。
- 首轮 21 项中 3 项失败：固定真实时间不足以等待缩时 Tween 完成、测试墙体低于棋子碰撞体、误设原近战射程。夹具改为等待实际位移完成、足够高的墙及明确测试射程；未为通过这三项修改业务规则。原始结果保留。
- 临时脚本、场景夹具、日志、截图与结果保存在忽略的 `tmp/B23/`。隔离 Unity 内临时入口已停用；正式场景、既有棋子预制体、技能及经济数值未保存或修改。

尚未覆盖原关卡完整手动输入、全部掩体/护盾/模因/被动的组合矩阵、多个随机位移分支、完整反应链、全分辨率和发行构建。B08/B09/B19 的专项验收仍独立，不因本轮开发检查而标记完成。
