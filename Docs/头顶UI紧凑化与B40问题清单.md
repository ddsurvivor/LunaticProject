# B40：头顶 UI 过大、遮挡战场

记录日期：2026-11-05。完成记录：2026-11-06。优先级：P0。状态：完成（18个棋子预制体、共享模板及PR4-2受控范围）。关联 [开发计划](战斗系统开发计划与验收.md)、[B34 血条记录](敌我血条重设计与B34记录.md)。

## 问题与来源

用户截图中，敌我头顶卡片体积过大，位置靠近棋子身体；多棋子聚集时卡片相互重叠，并遮挡角色、战场和行动菜单。既有功能与模板验收通过，不代表当前画面占用符合本次要求。

来源为用户本轮附图及三条明确修改要求。截图副本：[问题现场](../tmp/UIIssues/B40/用户反馈-头顶UI遮挡.png)。临时截图可被清理，以下文字要求为长期记录。

## 已确认的修改要求

| 项目 | 待修复要求 |
| --- | --- |
| 位置 | 玩家头顶 UI 再向上移，位于棋子头顶上方，避免压在身体上。敌人同样处理，并按各敌人不同模型高度分别调整预制体锚点/偏移，不能只套统一高度。 |
| 高度 | 进一步紧凑化；相同分辨率、Canvas 缩放和镜头条件下，高度上限为本轮反馈中当前高度的 50%。验收同时记录卡片和包含 Buff 行后的整体高度，避免把空间转移到卡片外。 |
| 姓名与 AP | 姓名和行动点放在同一行；AP 图标尺寸缩小为当前的 50%。 |
| 生命 | 血条独占一行。移除生命数值和其他额外说明文字。 |
| 背景 | 用户于2026-11-06更正为 **70%不透明度，alpha=0.70**；之前实现的alpha0.30方向有误，已修复。文字、图标和外框描边不跟随底色变淡。 |
| 文字删减 | 除姓名及下述 Buff 层数外，不显示阵营文字、AP 数值说明、弹药/能量、状态名称及其他说明文字；AP 使用图标，继续保持头顶无头像。 |
| Buff | 放在血条下方，只占横向一行；每项为固定正方形 icon，不显示名字，只显示层数。icon 边长约等于本轮修改前的 AP 图标尺寸，不是缩小后的 AP 图标尺寸。 |

## 实施约束与验收标准

- 延续敌我共享的正式头顶预制体模板，统一修改布局；不同敌人按实际高度调整各自预制体锚点/偏移，保留 Inspector 手动调整能力，避免逐场景复制整套 UI。
- 对比修改前后的同一场景、同一角色、同一缩放截图，记录高度与图标尺寸比例；区分背景透明度与文字/图标透明度，文字和图标仍须可读。
- 覆盖不同身高的玩家、普通敌人、矮小敌人及方尖碑，逐个核对头顶锚点。密集站位时检查人物、战场和行动菜单是否仍被严重遮挡，不能仅验证单个卡片能显示。
- Buff 必须始终为一行，不因数量增加变成多行或文字列表。执行时核对现有溢出/详情行为与此要求的兼容性，不能自行新增未经确认的交互规则。
- 在 1280×720、1920×1080 下保留实际运行截图；回归伤害预览、血条更新、AP 消耗、Buff 层数更新、死亡/池复用及镜头缩放，保持既有战斗规则。
- 2026-11-05登记时仅记录问题；后续实施见下文。B35其他面板仍按用户此前要求跳过。

## 实施结果与验收（2026-11-06）

分支 `dev_feature`。沿用 `Resources/UI/PieceOverheadStatus.prefab`，没有创建第二套头顶卡片。基础高度由100压至32像素（32%），带状态由138/172压至58像素（42%/34%），宽度244→200。姓名/AP同行，血条单独一行；AP图标上限22→11像素，Buff固定22×22、横向一行。首次背景alpha0.30理解有误，后续已更正为0.70，见末节；姓名/图标不随背景一起变淡。血条常显，原伤害预览和拖影保留；隐藏原生命数字、资源/阵营文字和状态名称。

状态图标仅显示实际层数（永久层数用∞）；百分比、来源数、剩余回合等保留在原点击详情中，不冒充层数。缺图使用空心图标回退；六格溢出沿用最后一格进入完整详情，不增加第二行或文字名单。发现旧状态面板的独立资源条背景仍覆盖人物，已连同其填充图形隐藏，展示层停用时沿原生命周期恢复。

6个玩家预制体和Enemy00–11共12个敌人均保存 `OverheadAnchor`，绑定到 `PieceDisplay.overheadAnchor`。按各自idle帧渲染边界标定高度并留0.25世界单位间距，模板屏幕偏移12→24像素；不是给所有敌人同一个固定高度。修改锚点Transform可即时调整位置；无锚点的历史入口仍有精灵边界回退。护盾沿用 `RangeBarrierStatus.prefab` 变体并同步紧凑尺寸，不改变其选择节点高度逻辑。

最终实际Unity 2021.3.23f1、PR4-2检查 **57/57通过，344帧，运行错误0**；包括尺寸/透明度、名称字形、AP/Buff图标、层数/缺图、原详情点击、血量/预览、长名、手调宽度/透明度/偏移、锚点即时调整、四种代表敌人的高度、菜单同屏、旧资源条隐藏、缩放、死亡状态隐藏及同实例重新Init。业务/编辑器编译通过。

另独立重新加载18个棋子预制体，与修改前资源对照，数值、技能、动作、动画引用等既有玩法字段一致。Unity保存补齐了旧资源缺失的默认字段，并整理Odin空列表/引用表示；对象级对照通过，静态检查另保留了既有字段及事件内容，只允许新增锚点、子节点链接、默认字段及RectTransform派生坐标缓存。20个正式资源（18棋子、共享模板、护盾变体）的原meta/GUID均保留。

实际截图已打开检查：[1280×720菜单与Buff](../tmp/B40/dense-1280.png)、[1920×1080](../tmp/B40/dense-1920.png)、[原关卡基本状态](../tmp/B40/battle-1920.png)。没有新增全场卡片自动排布；极端重合、所有敌人在所有镜头下的逐帧构图、自然通关与发行构建未覆盖，不宣称任意场景都零遮挡。

## 手动调整与维护

- 单个棋子的高度：打开其prefab，选择 `OverheadAnchor` 调整Transform；确认 `PieceDisplay.overheadAnchor` 引用保留。修改旧EnemyCanvas不能调整共享卡片位置。
- 所有卡片的样式/布局：编辑 `PieceOverheadStatus.prefab`，或通过UIManager指定Variant；调整宽度、字号、子节点位置、背景透明度、Head Offset及高度字段。共享样式初始化保留手调alpha；关闭Apply Shared Style可独立设置字体/颜色。
- AP图标的大小/间距可分别在ActionPointPipsUI中调整，默认值仍为22/27，不改变左下信息面板；仅头顶模板采用11/13.5。
- `Tools/Battle UI/Upgrade Compact Overhead Template` 仅升级旧版本一次；重复执行不覆盖后续手调。首次生成工具也产生紧凑模板。未改动AVG场景或恢复B35已跳过面板。

夹具、日志、截图、初轮失败与最终结果均在Git忽略的 `tmp/B40/`。最终证据为 `result.json`、`checks.json`、`semantic-assets.json`、`prefab-audit.json`、`anchors.json`、`baseline.json`、`copied-assets.json`、`unity-final-clean.log`、`unity-assets-final.log`。早期失败来自临时夹具对只读死亡属性/未绑定旧血条的使用、预览刷新时点及序列化比较器；标题高度不足导致字形裁切的问题已修正并验证实际字形生成。临时Unity测试入口已停用，正式代码不依赖测试类型。

## 透明度更正与固定斜角外框（2026-11-06）

用户更正为“不透明度70%”，并指出左下和右上斜角过大、压缩高度破坏框形。现已改为背景 alpha0.70。原 AVG PanelCut 素材上下切片各28像素，大于32像素卡片的总高度，会触发切片边角压缩；仅提高切片倍率也会缩细原描边。

改为 `CompactOverheadFrame` 原生UI几何：固定4参考像素斜角、1参考像素描边，尺寸变化只扩展直边；对角线按法线内缩，描边厚度一致。背景底色与金色描边沿用 AVG 原素材取色，背景70%不透明，描边保持清晰；不修改全局AVG贴图或其他面板样式。维持当前200×32/58紧凑布局、文字/AP/Buff尺寸及锚点。

只将共享模板原背景 Image 转为兼容的派生组件，保留其组件fileID和模板GUID，因此护盾变体自动继承，已有变体的alpha0.42手调覆盖也能保持。没有删除或重建子物体。升级菜单 `Tools/Battle UI/Fix Compact Overhead Frame` 幂等，不反复覆盖后续手调；新建模板也使用固定外框。

Inspector 可直接调整背景色调/不透明度、底色、斜角尺寸、描边宽度及颜色，支持撤销、多选及Variant。共享样式初始化仍保留背景alpha，不在运行中强制改回默认值。

最终隔离PR4-2真实运行 **76项通过，342帧，错误0**；六组200/240宽、32/58/80高的网格检查均保持斜角4、描边1、背景alpha0.70和描边alpha1，原头顶布局/AP/Buff/预览/死亡复用检查也通过。另核对模板/背景组件身份、升级幂等、护盾继承和变体覆盖。业务/编辑器编译与差异检查通过。
