# 掩体、高低差统一与 B18/B27 验收

日期：2026-10-30。B25 已按用户要求标记为跳过；B18 与计划指定随项完成的 B27 已完成当前共享规则及 PR4-2 受控验收。

## 已确认规则与实现

- 掩体 1–3 级分别减少基础攻击 20%/35%/50%，各级统一增加 20 个百分点闪避。全局数值及保护距离在 `GameConstSO` 配置，保护距离默认 2；场景 `CaverSlot` / `BattleObstacle` 配置等级，旧场景缺省为一级。保留原伤害公式中掩体先于护甲、暗骰及后续倍率的顺序，原必中特例保持原义。
- `BattleCoverQuery.Find` 按攻击者与目标脚点上方 1.2 的连线检查实体碰撞体，目标脚点至该命中碰撞体最近实体表面的距离不得超过保护距离。支持子碰撞体；多掩体取最高等级一次，同级稳定选择，不按射线返回顺序叠加。查询不依赖 `CurCaverSlot`、槽位是否已满或相机方向。
- 纯墙体、触发器、失效碰撞体、关闭的掩体和 `providesCover=false` 的纯障碍不授予保护。只识别显式掩体组件；不新增尚未定稿的通用墙体禁射规则。现有“弱防御射手避开掩体”的策略偏好改用同一查询，不把它解释为所有角色都禁止射击掩体后的目标。
- 槽位兼容接口不再额外添加 Shield/Conceal；非掩体来源的同名 Buff 继续按原规则生效。移除移动到达时仅凭附近槽位显示保护的旧分支，避免其与实际射线判定不一致。
- 掩体不新增完全挡伤判定，不独立阻挡状态、Buff 或击退。纯状态技能不因掩体降低命中；含攻击的技能继续遵守普通未命中与屏障效果门槛，命中后仍正常施加状态/击退。

## 高打低与查询统一

用户在本次明确回复“至少高出 1 个世界单位才生效”。实现采用大于等于 1 的边界，高差门槛在 `GameConstSO` 配置，默认 1；`layerSkill` 仍单独使用原来的 0.1 同层容差，两者不混用。

`BattleRangeRules` 统一玩家瞄准、确认命令、AI 合法性/落点/范围比较和只读查询：仅高打低的远程定点施放距离乘三，多层不继续累乘；同高、低打高、近战、支援保持基础距离。距离按既有玩家选点的水平面语义统一，高度由独立规则处理。

新增 `SkillReachKind.Auto/Melee/Ranged` 配置：显式标记优先；Auto 对旧内容依次按普攻引用或稳定 ID、已有敌人技能用途、相对近战射程兼容判断。保留旧技能资产，未批量改写或重序列化。含范围的道具与技能共用同一施放流程。

Circle 和 Grenade 可扩展选点距离，Grenade 的爆炸半径保持原值；以自身为中心的 Nova、Fan 和 Arc 几何尺寸均不扩大。跨层选点保留真实目标高度，鼠标读取实际棋子/地面高度；直接目标还须处于共享射程内，不再借单体选取小球越过最大射程。状态、层高、阵营及其他既有目标条件继续由 `SkillTargeting` 过滤。

范围边界、高亮与确认共用最终选点。正式结算位置改读不含图形离地偏移的 `SelectionPosition`，避免临界高差和 AOE 因准星抬高而与预览不同。AI 在当前层已有合法攻击时不先强制寻找楼梯，保留原近战限定与策略偏好。
