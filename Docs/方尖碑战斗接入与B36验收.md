# 方尖碑战斗接入与 B36 验收

2026-11-05，`dev_feature`。后续B37已按用户确认规则实现，见[光环与词条联动验收](方尖碑光环与B37验收.md)；下文保留B36阶段记录。用户授权“自己随机填一些数值”，本轮为 B36 配置固定的临时战斗数值，后续可直接在 Inspector 调整；每次运行不随机重掷。

成长按现有 `EnemyLevelGrowth.Calculate` 截断：等级1/2/100生命为60/62/258；100级动能/热能攻击加成为9/14，动能/热能护甲为9/19，火种护甲仍0。技能表中的伤害是技能基础值，实战叠加成长攻击并沿现有暗骰、护甲、掩体、暴击等公式计算，不承诺每次固定扣8/12生命。

正式预制体为 `Assets/Prefab/Battle/Enemy/Enemy10.prefab`，从停用草稿复制并独立保存，控制器和导航启用；近远程攻击复用 INST1skill 12帧，idle/move/hit/death维持草稿绑定。`skillidle/skillover` 留待引导技能。独立 `Assets/ScriptableObjects/ObeliskSkills.asset` 保存两条有稳定ID的技能，未修改全局技能库及既有敌人技能。

2026-11-06体型更新：按用户要求，正式方尖碑按待机帧非透明主体校准为与黑衣人等高，不使用包含透明留白的整张画布高度。精灵等比缩放从0.32改为0.8604967，可见主体高度约7.391667单位，与Enemy05一致；按可见底边与中心重新设置精灵偏移，根节点不缩放。PR0实例没有尺寸覆盖，继承正式预制体；其他使用该预制体的场景同步生效。制作工具新增“Match Black Suit Height”入口，并将首次创建逻辑同步为此规则。隔离Unity工程编译与等高对比渲染通过，记录在`tmp/ObeliskSize20261106/`；本次未重新执行战斗数值测试。

PR4-2 增加一只初始方尖碑，登记到现有 AIController.pieces，在原敌人附近的导航网格空位落点，不加入重复迷雾或增援列表。其他关卡未投放。正式SO中的数据才是运行时权威；草稿继续保持停用，不能替代正式Enemy10。

2026-11-06投放更新：按用户要求，在PR0BATTLE以方尖碑替换距离黑衣人较近的 `Enemy04 (1)` 军械无人机，并放在 `Enemy05` 黑衣人身旁约3米的导航面；该关维持4名敌人（军械无人机1、黑衣人2、方尖碑1）。方尖碑保留Unity的Piece标签，通过PieceData的“黑衣人”目标标签参与光环及词条联动。这是场景预置投放，未定义或实现黑衣人召唤、归属和随主人死亡消失的关系。新增护盾破碎后自身停机2回合的规则见B38记录。

## 手动调整与制作工具

`Tools > Battle > Obelisk > Create Combat Configuration If Missing` 仅首次生成；已有完整配置不覆盖，编号或路径部分占用则停止。SO和技能库使用Odin保存，不手改YAML。修改数值在 PieceDataListSO 的1010条目，技能在 ObeliskSkills，体型/帧/导航/碰撞/AI在 Enemy10 prefab；变更普攻名称不改变稳定ID。

关卡登记辅助接受指定AI实例并复用已登记的1010，重复调用不叠加；不覆盖已有关卡手调位置。

## 显示复用修复

验收发现既有精灵死亡淡出后重新 Init 会残留透明。`PieceDisplay.ResetForReuse` 在棋子Init时取消旧精灵淡出并恢复首次初始化捕获的透明度，保留原RGB及美术配置；避免上一生命的淡出完成回调停用新生命。其他战斗规则和死亡流程保持原入口。

## 范围

本轮交付 B36 棋子本体、临时攻击与AI、等级成长和PR4-2登记。B37的35%治疗光环、屠龙术传播、逆转敌我免疫，以及B38群体护盾均未实现。用户授权补临时数值，不替代这些尚未明确的机制规则。
