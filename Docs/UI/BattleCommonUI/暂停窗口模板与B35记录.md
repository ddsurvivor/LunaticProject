# 暂停窗口模板与 B35 记录

2026-11-05，`dev_feature`。B35 第二步迁移 U14 暂停窗口，其余面板仍按[清单](BattleUIPanelInventory.md)推进。

## 正式入口

- 模板：`Assets/Resources/UI/BattlePauseWindow.prefab`。
- `UIManager.PauseWindow` 实例化并绑定现有继续、重开和退出入口，不再运行时绘制暂停窗口。
- 主体嵌套 `AvgCommon/Panel.prefab`，标题嵌套 `Header.prefab`，三个按钮嵌套 `Button.prefab`；保留源 prefab 连接及正常/高亮/按下状态。字体沿用 AVG 设置使用的思源黑体。
- 根节点全屏遮罩拦截输入，`ActivePause` 独立持有暂停；关闭只释放本窗口，继续保留战斗快进倍率。重开和退出沿原场景转场与会话入口处理。

## 手动调整

在 Prefab Mode 编辑 `PauseWindow` 主体尺寸、位置、Header 及按钮的 RectTransform、文字、字号和颜色。运行时只绑定事件，不写回这些布局属性。建议保持根节点全屏拉伸及射线遮罩，保留 `ActivePause` 和 `BattlePauseWindow` 的标题/三个按钮引用。

差异化布局可从该模板创建 Prefab Variant，在对应 UIManager 的“暂停窗口模板 / Pause Window Prefab”槽指定；留空加载默认模板。绑定时只替换本实例持有的业务监听，不清空额外监听。

`Tools > Battle UI > Create Pause Template If Missing` 仅首次创建模板；文件已存在便返回，不覆盖手调。AVG 源模块本轮未修改；在本模板内覆盖模块属性可限制影响范围。

## 验收边界

专项使用 Unity 2021.3.23f1、PR4-2 隔离项目，检查真实嵌套依赖、生成器不覆盖、真实 Variant 不修改基模板、运行时不重建层级、重复绑定、暂停多持有者、继续恢复快进、实际重开和退出；截图覆盖 1920×1080、1280×720 和手调 Variant。临时脚本、结果和截图均在根目录 `tmp/PauseUI/`，不加入 Git。

最终运行专项 **33/33 通过、342 帧，暂停业务错误 0**；另有主菜单 Steam 初始化既有报错 1 次。编辑器检查确认三个模块嵌套引用、真实 Variant、基模板哈希不变及生成器不覆盖。业务与编辑器程序集编译、`git diff --check` 通过。已人工复核 `pause-1920.png`、`pause-1280.png`、`manual-variant-1280.png`；默认主体宽 620，Variant 宽 700、继续按钮字号 24，均保持居中且无溢出。临时执行入口在完成后禁用。

首次测试尚有开场动画持有暂停，第一次 Esc 关闭该窗口，未得到有效暂停截图；调整测试前置为取消开场并关闭旧窗口后重跑。主菜单 Steam 未启动产生的既有初始化报错单独计数，不算作本次暂停业务错误。按钮通过正式 Button.onClick 触发，尚未模拟操作系统鼠标与键盘，也未做发行构建或所有关卡覆盖。
