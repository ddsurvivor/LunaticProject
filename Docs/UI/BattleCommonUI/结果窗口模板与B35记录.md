# 结果窗口模板与 B35 记录

2026-11-05，`dev_feature`。本轮推进 B35 的 U15 胜负结果窗口，任务整体仍进行中。

## 正式入口与行为

`Assets/Resources/UI/BattleResultWindow.prefab` 使用真实嵌套的 AVG Panel/Header/Button，保留源模块连接及按钮状态。原 `BattleFinishPanel` 继续负责只读显示，`UIManager` 继续连接原 `BattleManager.OnClickQuitBattle`、重开及退出入口；没有新增胜负判定或奖励提交规则。

场景原来绑定结果面板时，初始化会停用旧实例，并将 UIManager 的结果引用指向正式模板；未绑定时也使用同一模板，不再生成另一套回退边框。旧场景资产本轮保留，后续引用清理单独处理。

结果根节点持有全屏输入遮罩与 `ActivePause`。Esc 不关闭结果；结果显示时停止快进、关闭旧暂停窗口。胜利继续仍在原离场入口一次性提交奖励，失败显示退出主菜单，双方均可重开。

奖励文字使用固定视口、纵向滚动和可拖动滚动条；长列表不会覆盖标题及按钮，短内容自动隐藏滚动条。每次显示重写预告并回到顶部，不写库存或投随机数。

## 手动调整

Prefab Mode 中可编辑 `ResultWindow` 尺寸、标题、按钮位置、字号、颜色和 `Rewards` 视口尺寸。Content/Description 高度由布局组件按文字计算，手调宽度和视口时保留其布局引用。业务运行只更新结果文字、按钮文案/显示状态和滚动位置，不覆盖手调尺寸、位置、字体或颜色。

可以创建 Prefab Variant，放入 UIManager 的“结果窗口模板 / Result Window Prefab”槽；为空时加载默认模板。根节点保持全屏拉伸，保留 `ActivePause`、两个按钮及 `BattleFinishPanel` 绑定。没有关闭按钮，以免留下空结果遮罩。

`Tools > Battle UI > Create Result Template If Missing` 仅首次生成，已有文件不覆盖。修改模板内的模块覆盖属性不会写回 AVG 源 prefab。额外按钮监听会保留，重复业务绑定只替换本实例原有监听。
