# 敌人等级成长系统

## 配置方式

1. 在战斗场景或敌人预制体的 EnemyController 上设置“敌人等级”，范围 1～100。越界脚本赋值在初始化时按 1～100 限制。
2. 打开 PieceDataListSO，在对应棋子数据的“敌人等级成长 / 每级成长”字典中配置：
   - Key：EnemyGrowthAttribute 枚举，带中文下拉标签。
   - Value：float，每升一级增加的数值。
3. 敌人初始化时先加载原有 SO 基础值（含扩展属性），再应用成长；结果存入 UnitAttrCenter，不修改共享 SO，也不修改技能威力。
4. 等级在初始化时生效。运行中只修改 level 不会立即刷新属性，需要再次初始化；重新初始化会补满生命、行动力、能量和弹药，并清除旧 Buff。

## 计算公式

```text
实际等级 = clamp(level, 1, 100)
最终值 = trunc(基础值 + 每级成长 × (实际等级 - 1))
```

trunc 表示舍弃小数，非四舍五入。只对字典中已配置的属性计算；空字典保留原基础属性。移动范围虽然在原系统中是 float，配置成长后也按本公式取整数（包含 1 级和成长值为 0 的情况）。

为避免 0.02 × 50 的二进制浮点误差使结果意外少 1，计算时将 float 转成 decimal 后再相乘。NaN/Infinity 成长按 0 处理。

以基础动能护甲 15、成长 0.1 为例：

| 等级 | 成长次数 | 最终护甲 |
| --- | --- | --- |
| 1 | 0 | 15 |
| 10 | 9 | 15 |
| 11 | 10 | 16 |
| 21 | 20 | 17 |
| 50 | 49 | 19 |
| 100 | 99 | 24 |

生命至少 1；行动力、能量、弹药、移动范围、分类型攻击与护甲不低于 0。暴击率、闪避率和伤害减免限制在 0～100；命中属性不强制限制到 100，允许超过 100 来抵消敌方闪避和掩体惩罚，最终命中概率仍由伤害系统限制。

## 默认成长方案

在 SO 上点击“为敌人填充默认等级成长”：

- minimumEnemyId 默认 1000，符合当前数据中玩家编号 1/2/3、101/102/103，以及敌人 1001 起的编号习惯。筛选是编号规则，不会扫描场景判断类型；若编号规则变化请调整参数。
- overwriteExisting 默认 false，只补齐缺失的 Key，保留手配值。
- 勾选 overwriteExisting 后，把所选编号范围的数据重置成默认成长。
- 支持编辑器 Undo，标记 SO 为已修改；正常保存项目即可。
- 此按钮只写入成长配置，不修改基础值；不会自动修改场景中怪物的等级。
- 新增系统不会自动替现有 SO 填充值：未配置的敌人保持原数值，按需点击按钮启用。
- 高编号玩家或召唤物数据可能被编号筛选选中，但运行时只有 EnemyController 使用等级成长。

默认曲线是线性增加、整数阶梯生效，适合从 1 级到 100 级逐步调参，不是指数倍率增长。

| Key | 每级默认成长 | 100 级相对整数基础值的增加 |
| --- | --- | --- |
| 最大生命值 | max(1, SO.maxHealth × 0.02) | 基础生命 ≥50 时约 +198%，即约 2.98 倍总生命 |
| 最大行动力 | 0.025 | +2（41、81 级各增加 1） |
| 移动范围 | 0.03 | +2 |
| 最大能量值 | max(0, SO.maxMana × 0.01) | 约 +99% 基础能量 |
| 最大弹药量 | 有基础弹药时 0.02，否则 0 | +1 |
| 通用攻击力 | 0.2 | +19 |
| 对抗值 | 0.05 | +4 |
| 动能攻击力 | 0 | 按怪物特点手配 |
| 热能攻击力 | 0 | 按怪物特点手配 |
| 火种攻击力 | 0 | 按怪物特点手配 |
| 动能护甲 | 0.1 | +9 |
| 热能护甲 | 0.1 | +9 |
| 火种护甲 | 0.1 | +9 |
| 命中率 | 0.1 | +9 个百分点 |
| 闪避率 | 0.05 | +4 个百分点 |
| 暴击率 | 0.05 | +4 个百分点 |
| 暴击倍率 | 0.25 | +24 个百分点 |
| 伤害增加 | 0 | 按需配置 |
| 伤害减免 | 0 | 按需配置 |
| 嘲讽值 | 0 | 按需配置 |

通用攻击力会参与每段伤害，所以默认不再同时增长三种攻击力，避免多处默认成长叠加。行动力和移动范围增长较慢，避免高等级敌人单回合行动次数或追击范围失控。以上为初始调参方案，尚未通过完整关卡难度实测。

示例：基础生命 100、行动力 2、移动范围 5、通用攻击 0、护甲 15：

| 等级 | 生命 | 行动力 | 移动范围 | 通用攻击 | 各类护甲 |
| --- | --- | --- | --- | --- | --- |
| 1 | 100 | 2 | 5 | 0 | 15 |
| 25 | 148 | 2 | 5 | 4 | 17 |
| 50 | 198 | 3 | 6 | 9 | 19 |
| 75 | 248 | 3 | 7 | 14 | 22 |
| 100 | 298 | 4 | 7 | 19 | 24 |

## 基础数值来源与兼容性

- 生命、行动力、移动、能量、弹药、暴击等沿用 PieceData 的现有字段及 attrDic。
- 增加了 PieceData.attackDic（“分类型基础攻击力”），可在 SO 中配置动能、热能和火种攻击。显式配置覆盖该类型的场景基础值；未配置时保留场景/预制体原值。
- 护甲继续使用 PieceData._armorDic。
- UnitAttrCenter 首次敌人初始化会保存场景/预制体的 AttrCenter、ATK、CON、嘲讽基础快照。以后先恢复快照，再加载 SO 和当前等级，防止重复初始化累加。
- 每个实例使用独立的 AttrCenter 副本；同一 SO 的 1 级敌人与 100 级敌人可以同时存在。
- 玩家继续走原初始化路径；成长字典不对玩家自动生效。
- 初始能量沿用当前系统“初始化补满最大能量”的规则，暂未增加 initialMana 成长。
- 技能威力、攻击次数、技能射程、掉落率和各类元素克制加伤未纳入成长，避免修改共享技能对象或把掉落配置与战斗属性混在一起。
- 成长后的属性直接被现有 AI 和伤害结算/预览读取；详见 [DamageSystem.md](DamageSystem.md)。

- Assets/Scripts/Battle/Controllers/PieceController.cs：敌人初始化分流。
