# 碰撞实际损失修复与 B09 记录

日期：2026-11-04。范围：B09 中 D03 已确认的碰撞基数及单次结算修复。

## 问题与修改

旧配置击退读取 `HitBackEffect.hitBackDamage` 固定值，聚能默认击退使用展示伤害之和乘 0.4，二者均不能代表实际生命损失。过量伤害及屏障吸收时会产生错误基数。

现在从 `DamageManager.Settlement.DamageResults` 汇总本次直接伤害各段 `HpLoss`，传入配置击退和聚能默认击退。快照不包含过量伤害、被动派生伤害或屏障吸收；聚能延期回调携带该数值，不在释放时读取剩余生命。原击退距离公式和导航规则保持。

`BattleCollisionImpact` 使用整数运算计算 `floor(actualHealthLoss × 0.4)`，避免浮点舍入与乘算溢出；每次击退只消费一次碰撞，消费标记先于生命回调。路径在首次碰撞处停止，移动者及首个被撞棋子各结算一次，撞墙仅结算移动者。重复参与者、重复/重入提交不重复扣血，零基数不发送伤害事件。使用直接生命提交，保留 Collision 来源与根行动，不重新执行技能或派生击退。

旧 `hitBackDamage` 字段为资产兼容保留并隐藏，不再参与计算；未重序列化技能库、棋子数据、预制体或场景。
