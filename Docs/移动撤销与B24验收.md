# 移动撤销与 B24 验收

日期：2026-10-30。B24 已按当前导航移动和 PR4-2 受控场景完成实现及验收。

## 实现范围

复用原有撤销按钮和移动流程，撤销记录统一由 `BattleManager.MoveUndo` 持有，鼠标确认移动与程序化玩家移动共用付款、导航提交及到达确认入口。只保留当前行动段内最近一次已完成的纯移动；再次移动覆盖旧记录，成功撤销立即消费记录，因此允许反复“移动—撤销”，不允许连续撤销两次。

快照保存付款前位置、朝向和实际 AP，并记录付款后 AP、对象初始化版本、导航终点、规则抽样版本以及参战者资源/状态的一致性信息。撤销按原值恢复 AP，不按当前费用配置重新计算；弹药、能量及其他单位资源必须保持一致，不替它们回滚。使用 NavMesh 的过滤和 Warp 同步导航，原位置不可用、被占用或状态已变化时拒绝退款。

## 失效边界

- 其他动作成功提交 AP 付款，包括固定费用、装填、技能、道具、警戒和模因换装，立即销毁旧记录；付费后麻痹取消或散热伤害也不能保留旧撤销。确认前被拒绝且未付款的命令保留原记录。
- 警戒/夹击反应排队即失效，即便反应最终取消或没有造成掉血。有效伤害、生命变化、旧 Buff 增减/来源变更、精确状态施加/解除、治疗区到达和场景交互均使记录失效；其他参战者的位置、资源或状态变化也由一致性校验拒绝。
- `BattleRandom` 抽样版本只递增；发生规则抽样即失效，麻痹成功通过后也不能撤销来反复尝试。撤销不恢复 Unity 全局随机状态，避免重投或回滚共用随机序列的表现/剧情。
- 在途、导航提交失败、超时、偏离终点、死亡、初始化复用、交棒、战斗停止及聚能行动段退出时不能撤销。普通回合与聚能额外行动段各自隔离，进入选人和退出额外行动清除记录。
- 保留现行自动交棒规则：最后一点 AP 用完并交棒后没有撤销窗口，不跨回合恢复。暂停时暂时禁止执行，恢复后没有其他变化则仍可撤销。
- 撤销取消当前选择/移动预览，只刷新交互和 Idle 表现，不调用 `StopMove`，不重放治疗区、到达效果或掩体特效。自动重选当前行动者保留本段快照，真正交棒仍显式清除。

上述不可逆边界是按开发计划中“由实现确认”的要求采用的保守实现，不新增整轮回滚或重投规则。正式场景的 `dragMove` 当前均为 0；未启用的直接拖动瞬移旧分支不新增撤销支持。
