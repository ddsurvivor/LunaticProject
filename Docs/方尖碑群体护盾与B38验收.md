# 方尖碑群体护盾与 B38 验收

2026-11-05，开发分支 `dev_feature`。用户在本会话明确采用两组规则；B38 已实现，等待人工试玩验收。

## 已确认规则

- 主动技能消耗 2AP，无冷却。护盾随方尖碑移动，球形半径 8，独立耐久 40；破坏、来源死亡或离场时结束。当前护盾存在时拒绝重复施放且不扣费。
- 2026-11-06补充：护盾被击破后，来源方尖碑立即停机，不能行动且治疗光环暂停；持续接下来的两个自身普通回合，第三个普通回合恢复。复用现有眩晕计时，聚能不减时；来源死亡、离场清盾及旧生命护盾不会施加停机，重复破盾回调只处理一次。
- 以施法者或爆炸源的世界位置判定内外，只拦截外→内。球面边界算内部，使用三维距离；内→外、内→内、外→外均放行，不按阵营筛选保护目标。
- 使用统一伤害公式计算本段伤害，再扣范围护盾耐久；低于耐久全部吸收，等于耐久破盾且全部吸收，超过耐久仅溢出落到原目标。攻击护盾自身只扣独立耐久，不额外指定一个内部受害者。
- 多段逐段结算。AOE 对每个受影响目标按当前目标列表顺序分别消耗耐久；爆炸使用爆炸源的位置。DOT 直接结算到单位，不经过此拦截入口。
- 全部伤害段被吸收时，原目标不获得攻击附加状态、模因或击退；有段到达目标后沿用现有附加效果规则。原阻速场位于范围护盾之后，其破盾当次整次攻击仍全吸收的旧规则保持。
- 护盾可独立选择攻击，并有无头像、常显耐久的独立血条。不进入行动队列、胜负、掉落和普通棋子击杀回调；拒绝治疗/无直接伤害的支援技能。

## 正式资产与手动调整

| 入口 | 用途与可调整内容 |
| --- | --- |
| `Assets/Prefab/Battle/Enemy/Enemy10.prefab` → `BarrierEmitter` | `radius`、`durability`、`barrierPrefab`；影响下一次施放，调整半径时新护盾美术按比例缩放 |
| `Assets/Prefab/Battle/Enemy/ObeliskRangeBarrier.prefab` | 独立实体、选择节点、SpriteRenderer、idle/death 序列和透明度；`targetOffset` 定位选择节点，`authoredRadius` 表示美术制作时的基准半径 |
| `Assets/Resources/UI/RangeBarrierStatus.prefab` | 共用 `PieceOverheadStatus` 的正式 Prefab Variant；隐藏 AP/弹药/能量，常显耐久，可独立改偏移、头顶高度、布局、字体与配色 |
| `Assets/ScriptableObjects/ObeliskSkills.asset` | 稳定 ID `obelisk_range_barrier`，自身目标、独立 AI 用途、动画索引和描述；无冷却字段 |
| `Tools/Battle/Obelisk/Apply Confirmed Range Barrier` | 首次补齐资产和配置；再次执行只补缺失项，不重建已有模板或覆盖手动参数 |

护盾球体没有整球碰撞体，以免挡住内部棋子的点击。靠近方尖碑的橙色小节点是独立攻击目标；逻辑球心仍是方尖碑位置。球形三维判定与现有二维精灵表现分开，画面中的圆形素材不充当物理球面。

## 结算与预览可靠性

`DamageManager.ResolveSkillTarget` 统一拦截技能/普攻/爆炸的直接伤害；`BattleManager.AbsorbRangeDamage` 按射线进入球面的距离由外到内处理嵌套护盾，同距沿注册顺序处理。独立扣耐久保留根行动，不触发内部目标受伤/击杀事件。

预览使用真实结算公式，在耐久副本上模拟先前 AOE 目标和多段伤害，不修改真实耐久、生命或随机状态。先前目标可能未命中时，最小伤害分支保留护盾耐久。范围 UI 提供当前目标顺序的只读入口，回调不递归查询；持续刷新预览以响应耐久和目标顺序变化。

来源生命版本变化、死亡或禁用后，护盾立即失去拦截资格，随后清理实体。聚能中的普通外部攻击延期结算；聚能破盾立即更新逻辑耐久，冻结破坏首帧，退出后按原队列播放，死亡动画纳入动作等待后再交棒。
