# 方尖碑结构草稿与 B36 记录

2026-11-05，`dev_feature`。用户要求跳过 B35 剩余面板后推进 B36。本文为初始草稿阶段记录；用户随后授权临时数值，正式战斗接入见[最新验收](方尖碑战斗接入与B36验收.md)。

## 本轮范围

先制作 `Assets/Prefab/Battle/Enemy/Drafts/Obelisk_Draft.prefab`，从黑衣人 `Enemy05` 复制通用棋子结构。保留 Piece 标签、Layer 11、EnemyController、UnitAttrCenter、PieceDisplay、EnemyCanvas、碰撞和导航组件及内部绑定（RangeUI沿用来源留空，正式行动时由 SkillManager 按需实例化），断开来源外层 prefab 继承，避免来源变化自动带入行为。

明确的1级生命60、热能护甲10（Ranged）、动能护甲5（Melee）、火种护甲0（Electric）写入草稿回退属性；草稿快照标注机械身体及黑衣人标签。候选 ID 1010 尚未登记到 PieceDataListSO。草稿不是正式 SO 数据，不能据此宣称“从 SO 初始化”验收完成。

手动绑定 INST1idle 6帧、move 5帧、skill 12帧、hit 2帧、death 10帧，包含0000帧并按四位编号排序。`skillidle` 6帧、`skillover` 10帧仍保留素材，不塞入没有对应播放语义的字段，后续 B37/B38 明确引导阶段后接入。攻击和闪避列表不继承黑衣人帧；现有闪避按空列表回退待机。

清空来源的五类棋子事件、UnitAttrCenter死亡事件及可用技能/行动/被动，移除来源自疗或自爆行为；不继承来源技能定义。精灵按2.4单位图像高度缩放并按底边落点，碰撞/导航/Canvas仅为初步体型配置，正式关卡仍须验证脚底、遮挡、血条与导航。

## 安全的草稿状态

根节点默认停用，EnemyController 与 NavMeshAgent 也停用；未登记到正式棋子 SO、场景、AI、波次、迷雾或对象池。未确认的行动力、移动、攻击、速度采用0占位而非设计数值；AI枚举等未确认字段不作为可用战斗配置。不要直接启用投放；当前 TurnSpeed 有默认回退，所以速度0也不代表已实现“不能行动”。

`Tools > Battle > Obelisk > Create Draft If Missing` 仅首次生成；已有草稿直接在 Prefab Mode 手调，生成器不覆盖。已有 Enemy00–09/11 和正式 PieceDataListSO 不修改。
