# 剧情顺序列表

整理日期：2026-10-12。依据当前 `Assets/Resources/Story/*.bytes` 中保存的 Excel 第一工作表、A 列事件指令与 B 列中文内容。`Assets/Resources/剧本.xlsx` 仅含编号示例，不含 NEXT / BATTLE，未作为剧情顺序来源。

阅读规则：`→` 表示指令明确衔接；`〔战斗：场景〕` 表示插入战斗；`END` 表示本段结束并保存进度。不同编号的段落之间若没有 NEXT / BATTLE，须由地图或任务系统触发，不能只按文件名认定自动衔接。分支是互斥或可重复的路径，不是所有节点依次播放。

`NEXT(剧本,行号)` 跳到指定表格行，省略行号时从开头读取；表内行号包含第 1 行表头，0 表示从开头读取。`BATTLE(场景,战后剧本,预设)` 中第三参数是战斗预设（省略为 0），不是剧情编号或胜负判定。下文 WIN / LOSE 来自 CHECK 检定变量，不应理解为战斗胜负。
