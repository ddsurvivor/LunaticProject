| 边界 | 实际执行与结果 |
| --- | --- |
| 敌方回合插入 | 在正式速度调度器中让敌方与两名友方依次就绪，通过聚能入口选两人；控制权交接正确，敌方普通回合开始/结束各一次，结束后由原队列选中已满条友方 |
| 额外行动恢复 | 两人额外行动依次执行，普通 AP 快照各恢复一次；额外行动不触发普通 TurnStart/TurnEnd、不消费队列进度；被中断回合不扣聚能冷却，退出后仍为 3 |
| 最后 AP 的在途弹道 | 临时技能使用真实对象池 ROCKET 与正式战斗动作协程；支付最后 1 AP 后减慢真实 Tween 并请求聚能，在途期间保持请求且不能选人；命中并结束表现后才开放选人，目标生命 10000→9988，随后聚能正常进入和退出 |
| 额外行动者死亡 | 在两人聚能的第一人行动期间提交真实自损致死，转入第二人；死亡者保留死亡时剩余 AP，不恢复普通 AP 快照，不能再控制、不能再入队；释放期死亡事件仅一次 |
| 禁用管理器 | 在正式聚能协程中禁用管理器：存活角色 AP 快照恢复，速度调度和双方输入撤销，活动者及聚能请求清空；延期回调被丢弃，无延迟执行 |
| 胜利与失败 | 分别在真实聚能插入过程中调用正式胜败入口；聚能尚未退出时不呈现结果，结束额外行动后先释放一次延期效果，再呈现对应结果，清理活动者、输入、聚能与调度状态 |
| 单场景卸载 | 在真实聚能中带着未释放回调重载场景；旧角色和管理器已销毁，旧回调不执行，新管理器没有聚能、选人或释放队列残留 |

测试通过正式入口请求、确认聚能及触发结果；通过反射设置就绪队列和调用正式战斗动作入口，AI 的 Update 暂停，以便稳定触发边界。不是操作系统键鼠端到端，也不是自然胜败或全关卡长测。弹道使用临时必命中技能隔离随机命中，不代表某个现有技能的数值验收。
