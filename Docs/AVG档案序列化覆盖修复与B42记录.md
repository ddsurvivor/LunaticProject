# AVG 档案序列化覆盖修复（B42）

更新：2026-11-07。分支：`dev_feature`。状态：**完成（AVG资产修复、独立加载及B41受控回归范围）**。用户要求执行下一项改动，本轮处理B41已记录的三条Odin反序列化错误；不恢复已跳过的专项验收，也不引入新玩法规则。

## 问题与原因

迁移前后读取原AVG场景都会报告三条 `Failed to parse array length from data`，数据分别为空、`TEST`、为空。调用栈对应 `PLAYERPROFILE` 内的 `List<ItemPack>`、`List<string>` 和 `List<int>`；B41已将其作为既有错误保留。

问题位于 `Assets/Scenes/AVG.unity` 的共享单例实例（场景块121690303），而非磁盘JSON存档。该实例给GM组件保留736条Odin序列化相关覆盖，其中包含强制节点数组长度42，以及732条按下标修改节点名称/值的记录，最大下标354。旧覆盖与当前继承结构不一致，普通字段值被套用到数组长度读取位置，导致解析错误。

共享 `Assets/Prefab/单例.prefab` 的档案结构本身可读取；恢复继承后，场景档案与该预制体一致，三个列表均有效。GM在Awake中创建并初始化当前工作档案的既有流程保持不变。

## 修改范围

- 在隔离Unity工程中，先复现三条错误，再确认GM组件没有其他业务字段覆盖，使用 `PrefabUtility.RevertObjectOverride` 撤销该组件过期的序列化覆盖。
- 最终移除735条过期覆盖，保留单例的继承与引用元数据。正式资产只修改 `Assets/Scenes/AVG.unity` 的这一组Prefab实例数据；其他653个场景对象块保持原始内容，没有增删场景对象。
- 保留GM、DataManager、音频、市场、转场及剧情阅读器的引用；公共单例预制体、B41共享战斗阅读器、全部业务脚本及其他场景文件均未改动。
- 清理Unity重存顺带产生的两个无关对象块变化，正式差异仅为该实例数据的2940行过期覆盖删除。没有更改档案类型、JSON读取逻辑、存档槽或资源数值。
