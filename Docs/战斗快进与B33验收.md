# 战斗快进与 B33 验收

2026-10-30，在 Unity 2021.3.23f1 的 PR4-2 隔离副本执行。

## 实现与配置

- 右上角双箭头和齿轮并排。快进使用 Toggle，1x 为浅色，3x 为金色，同时显示倍率文字；图标直接绘制，不依赖字体符号或新位图。
- UIManager 的 `fastForwardKey` 默认 `Space`，`None` 禁用；`fastForwardHoldThreshold` 默认 0.25 真实秒数。修改绑定应避开 Esc 暂停及现有功能键。旧结束回合按钮原绑定空格，但战斗初始化已禁用；快进在 EventSystem 前清除选中对象，防止同一次空格同时触发 UI Submit；输入框输入期间不响应。
- 短按在松手时切换。达到阈值后临时开启3倍速，松手恢复按下前状态；原本已为3倍速时，长按结束仍保留3倍速。失焦、丢失松手状态或窗口占用输入会取消本次按压并恢复；战斗停止时统一回到1x。
- TimeManager 优先级为暂停→命中停顿→战斗倍率。命中停顿不乘3，持续时间按真实秒数，在显式暂停期间冻结。恢复时保留当前快进选择，物理步长随有效倍率恢复。
- 齿轮使用 BattleScene.prefab 引用的原 SettingPanel.prefab，已有设置实例时复用；窗口通过 ActivePause 独立持有暂停。战斗实例启用原关闭按钮并适配尺寸，关闭或 Esc 返回后保留原快进状态；不改 AVG 场景及原设置 prefab。
- 普通行动、导航、AI、聚能与速度调度沿用战斗缩放时间。按钮反馈、血条拖影、跳字、通知、面板和页签表现使用真实时间；转场原有真实时间计时保持不变。快进状态不进入全局设置或存档，胜败、离场及时间管理器停用时清除。
