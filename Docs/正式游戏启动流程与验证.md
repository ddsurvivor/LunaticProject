# 正式游戏启动流程与验证

## 正式入口

`StartScene` → 点击“新游戏” → `OPCG` → `Playing` → 自动开始 `PR0`。

- Build Settings：StartScene 第一位，OPCG、Playing 已启用；保留 AVG 原有启用状态，未启用其他战斗/调试场景。
- StartScene 实际按钮的 `onPointerUp` 绑定 `StartMenu.OnClickStart`，菜单目标为 OPCG；空配置同样回退 OPCG。
- 新游戏创建全新 PLAYERPROFILE，清空残留特殊剧情和战斗设置；转场期间重复点击不重建档案，不覆盖原有磁盘存档。
- OPCG 保留同一 GM 与档案，正常播放结束后展示 LOGO/文本并进入 Playing；Esc 或 `Openning.Skip` 可跳过。视频缺失、错误、准备/播放超时均继续后续流程；离场清理本片头动画和视频回调。
- Playing 关闭 `isDebugMode`，由 GM 转场完成后调用地图剧情入口，自动开始 PR0 并消耗新游戏标记。
- 编辑器/Development 审核辅助仅在进入 AVG 后安装审核档，不在正式启动时注入。安装新审核档后刷新 DataManager，保留原有审核功能。

证据：`tmp/FormalGameFlow/result.json`、`checks.log`、`unity.log`。最终源码补充冒烟结果见 `smoke-result.json`、`smoke.log`、`smoke-unity.log`，空场景配置回退及正式链通过；进入 AVG 后审核档安装/刷新通过，但其 Odin PLAYERPROFILE 反序列化产生错误，导致额外的 AVG 无错误检查失败。没有将此结果记为全部通过。
