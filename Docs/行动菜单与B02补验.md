# 行动菜单与 B02 补验

日期：2026-11-05。分支：`dev_feature`。关联[开发计划](战斗系统开发计划与验收.md)和[原 B01–B08 验收记录](战斗系统B01-B08验收记录.md)。

## 修复

实际 PR4-2 菜单中发现，17 条棋子虽然保留稳定技能 ID，技能库引用却为空；普通攻击因此拿到没有范围的历史占位配置。只在当前编辑器会话恢复引用不足以解决问题，必须验证独立冷启动。

- 棋子目录列表改为只由 Odin 序列化，移除 Unity 对同一列表的重复保存，保留字典和嵌套引用。
- 使用已有 `Tools/技能配置/恢复丢失的角色技能库绑定` 工具补回引用；公共技能库由 Unity 原生重存。此前先加载目录与先加载技能库的结果不同，原生重存后先加载目录的冷启动也通过。
- 不增加运行时自动绑定、默认技能库或按名称猜测的兜底。18 条棋子的其余公开字段与修复前快照完全一致，公共技能库的全部技能定义与重存前快照一致；方尖碑独立技能库保持原引用及文件内容。
- 长列表和长详情原先分别被顶部行动序列和左下信息遮挡。菜单和详情改用同一可用区域查询，按当前可见行动序列、快进控件、角色信息及其伸出的立绘/AP 图形边界避让；溢出内容继续通过原 ScrollRect 滚动。

没有变更技能 ID、攻击范围、伤害、费用、角色数值、正式场景或预制体。旧配置中部分普通攻击的名称为空，但其范围和伤害有效；本轮未用命名规则误判或重写这些技能。

## 受控运行验收

Unity 2021.3.23f1，实际 `PR4-2BATTLE`，最终 110 项检查全部通过，Play 错误 0。最终冷启动先加载棋子目录，再加载技能库，不调用恢复工具即可得到 18 条有效引用；完整字段、技能定义及专属库检查通过，重复运行恢复工具不改资产。

| 范围 | 检查内容 |
| --- | --- |
| 近战、远程 | 展开/悬停/进入选择/取消不扣费；命中实际临时敌方；重复确认只扣一次 AP，远程只扣一发弹药；表现结束恢复菜单 |
| 主动技能 | 详情与费用预览；选择/取消不扣费；确认只扣一次 AP/MP；完成后恢复菜单 |
| 道具 | 正式手榴弹的选择、取消、确认与库存；正式医疗单元即时治疗及一次扣费 |
| 资源变化 | AP、MP、弹药、材料不足；旧库存行失效；选择期间 AP/MP/弹药/库存消失后拒绝施放，不额外扣费 |
| 列表与详情 | 空技能/道具占位；30 条技能实际滚轮滚动、末行可见且射线首命中后点击与取消；超过 10 条道具；长详情滚动；双分辨率 HUD 避让 |
| 生命周期 | 离开按钮的宽限、进入详情后续留、离开后关闭；重开不重复生成行；隐藏清理详情和费用预览 |

另重新生成并执行旧道具定向回归，18/18 通过。初次生成因临时替身缺少后续新增接口而不能编译；仅补齐 tmp 中的接口替身后通过，未修改业务以迁就替身。业务与编辑器程序集均通过 Unity 编译配置检查，既有警告保留。

## 隔离、证据与边界

所有夹具、临时技能/库存、脚本、日志、截图与结果位于 Git 忽略的 `tmp/B02Menu/` 及其 tmp 隔离 Unity 项目。临时测试入口已停用。使用瞬时玩家资料和隔离持久化目录，不回写正式存档；保留用户已有未提交改动。
