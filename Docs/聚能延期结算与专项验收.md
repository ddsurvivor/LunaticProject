# 聚能延期结算与专项验收

日期：2026-10-30。范围：B14、B15、B17、B29的现有棋子、爆炸物、聚能调度与PR4-2受控验收。

## 已确认规则

用户明确纠正“不是免疫伤害，而是那些爆炸伤害会在聚能结束后才结算。例如自爆的无人机、会爆炸的油桶”。因此B14改为伤害延期，没有任何范围/爆炸免疫。

聚能参与者的直接技能/攻击即时结算HP，直接范围攻击仍沿原技能规则。敌方或未参与者攻击、插件/碰撞派生伤害及无来源旧扣血入口延期；爆炸桶、自爆敌人、召唤自爆兵、电浆脉冲和死亡触发效果到退出后正常结算。参与者和未参与队友届时都可能受到伤害。

B10/B11已确认的普通回合DOT、付费行动散热伤害/麻痹及状态自伤保持原触发时机，不将这些规则改成延期或免疫。尚未正式定义的环境伤害不能仅根据伤害类型名称推断为直接攻击。

## 实现

- BattleManager.BurstDeferred持有本场触发顺序队列与可暂停引信。聚能开始将已有引信连同剩余时间移入队列，新触发效果追加；多人角色交接不释放。退出后逐项结算，连锁追加队尾，保留原行动根ID。
- PieceDisplay独立冻结受击/死亡首帧，不占用普通一次性播放锁，避免冻结画面阻塞聚能输入。直接伤害造成的HP变化立即提交；敌方受击、命中镜头、死亡事件、被动通知及击退/夹击/警戒等待释放。致死立即撤销棋子行动和模因状态。
- 普通桶、正式Enemy11无人机及电浆桶、SelfExploreSummonPiece、SelfRevive延迟入口使用战斗引信。爆炸目标按实际爆炸时的原范围查询，伤害与附加效果仍经过原PieceSkill/DamageManager，不补免疫或改概率、伤害数值。
- 爆炸物记录位置、Rigidbody、NavMeshAgent、Animator及原本播放中的粒子快照；聚能期间固定位置并暂停，结束或清理时归还。Init或停用先释放旧快照；重新启用在新位置重新登记。
- 死亡回收排到已触发爆炸之后，淡出也纳入表现等待。正常/提前结束都先释放再交还普通控制，胜负在冻结结果清空后提交。禁用、主动退出、卸载清空旧队列，不补发已取消关卡的效果。
- 每个事件校验Unity对象、启用状态、棋子Init版本和对象池租期；组件停用取消本组件引信。重建后的旧回调不能作用于新一轮对象。
- B17不再改共享材质。按渲染器保存引用并创建实例副本，AllIn1材质使用灰度关键字，其他材质使用主纹理/颜色/透明度灰度回退；运行中新增物件和粒子也纳入。选中者保留彩色，取消、退出与清理恢复原引用并销毁副本。Canvas界面沿用现有样式。

后续环境模块应调用 `ScheduleWorldEffect(owner, delay, actualCallback, action)` 或 `TryDeferBurstEffect(owner, actualCallback, action)`；回调传实际实现，避免再次进入同一排队入口。组件OnDisable调用CancelWorldEffects，并在拥有爆炸物物理快照时调用ReleaseExplosiveBody。直接伤害必须传真实BattleDamageSource，不能依赖Unknown绕过延期。

## 验收方法与范围

Unity 2021.3.23f1，在根目录tmp内的隔离项目加载PR4-2BATTLE。规则矩阵暂停AI/普通调度并控制HP/技能/位置；多人支付、选人、交棒、提前退出另走正式速度调度与按钮入口。没有把人工提高HP和构造技能当作原始关卡平衡结果。

正式Enemy11、Barrel3预制体直接从资产实例化，保留真实死亡事件与技能绑定；普通桶另含运行时长引信夹具。导航夹具检查水平位置锁定并容许NavMesh地面吸附0.1米误差，不把0.05米落地吸附当作爆炸物移动。
