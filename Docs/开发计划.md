## 执行约定

1. 每次执行先读本页“当前阶段”，只选一个已授权任务；再按[程序框架](程序框架.md)读取该任务相关模块和规范。
2. 核对现状 → 最小修改 → 针对性验证 → 更新状态与结果。用户新要求先补入本页，记录规则、范围、完成条件和依赖；候选未经确认不自动实施。
3. 开发验证通过写“待用户验收”，不能自行标成用户已验收。当前阶段完成后只在这里更新下一项，结果流水写入结果页。
4. 一次对话未完成的任务保留当前进度、阻塞和下一步，不因对话结束自动升级状态。
