- AudioManager 动态创建的 BGM、音效池分别接入现有 MainMixer 的 BGM/SFX 分组；音源本身保持素材倍率，四档设置仅由 Mixer 衰减，避免重复乘音量。新增 `PlayVoice(AudioClip, volume)` 接入 Voice 分组；当前项目未发现既有角色语音播放入口或语音指令，不将普通音效改归语音。

## 循环声音音量未生效补修与无边框窗口主流化（已实现，待用户场景验收）

2026-11-18 用户复测反馈：音量调节仍无法应用到在播循环声音。检查确认根因为**场景预置的旧音源未接入 Mixer**：StartScene 的“永夜无期主旋律loop”（激活在播）与“Afterworld(Final Loop Version)”、AVG 的“光圈二号-FINAL”、OPCG 的 bgmSource 均为场景内 AudioSource，`OutputAudioMixerGroup` 为空，完全绕过 MainMixer——上一轮修复只覆盖了 AudioManager 动态创建的音源，未覆盖这些场景音源。

- AudioManager 新增兜底：初始化及每次场景加载时，把场景内未接入 Mixer 的 AudioSource 统一归入 BGM 组并输出警告日志；在播音源改组分立即生效，循环背景音乐实时响应音量滑块。常驻对象（GM/音源池）不在此列，已接入分组的音源不受影响。
- 无边框窗口主流化检查：Unity 的 FullScreenWindow 模式下 `SetResolution` 传入的尺寸被忽略、实际按桌面分辨率开窗，原实现会让分辨率下拉显示与实际不符。已改为无边框时强制使用 `Screen.currentResolution`；同时切到无边框模式时禁用分辨率下拉（参考主流游戏做法：无边框=桌面分辨率，不可调），全屏/窗口保持可选。窗口模式仍保留“实际尺寸限制在桌面内、不改玩家索引”的现有行为。
- 其余核对结论：三档映射（ExclusiveFullScreen/Windowed/FullScreenWindow）、旧 isFullScreen 迁移、切模式保留分辨率索引、保存/恢复默认同步，均符合主流游戏设置做法，未改动。

验证：主程序集编译0错误（Unity 2021.3 C# 编译器）。场景音源归属已逐个核对（StartScene 2 个循环 BGM、AVG 1 个一次性音源、OPCG 1 个开场 BGM，其余场景无场景音源）。未运行 Unity Play Mode 或完整游戏；循环背景音乐实时调音与三档窗口切换的实机表现待用户场景验收。不提交。
