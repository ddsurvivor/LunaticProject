# 模因框架接入说明

当前实现提供模因配置、队伍解锁、双槽装配、四类来源合并、目标过滤、抗性与概率判定、只读预览、已有 Buff 效果和自定义效果接口。已连接正式技能结算、玩家与敌方夹击/警戒、插件内爆的反应标记。B10已接入细胞自毁/散热故障的精确状态、指定标签解除及散热恢复抗性，见[接入及验收](细胞自毁与散热故障接入及验收.md)。本阶段不新增界面，也不实现混乱、逆转敌我等完整 AI 行为。

## 配置入口

在 Unity 资源创建菜单选择 Game/MemeCatalog，新建目录资源。把资源指定到 DataManager.memeCatalog，或仅指定 BattleManager.memeCatalog 覆盖当前场景。没有配置目录和模因来源时，现有战斗保持原有行为。

每个 MemeDefinition 使用发布后保持不变的正整数 id。重复编号、无效概率、空效果或无效枚举不能触发。未实现词条设 enabled=false，可作为无效果的禁用占位项。

| 字段 | 用法 |
|---|---|
| targetBodies | Biological、Mechanical 或 All；与伤害类型、阵营无关 |
| targetRelation | Hostile 默认只影响敌方；Friendly 影响友方（包含自身）；Any 不限制 |
| requiredTargetTags | 必须全部匹配 PieceData.memeTargetTags，区分大小写 |
| triggers | AttackHit 或 SupportResolved，可组合；没有伤害段的技能按支援事件处理 |
| requiresRecognitionSuccess | 要求技能开启现有模式识别且结算结果为成功/大成功，不自行额外掷骰 |
| chancePercent | 0至100的词条触发概率；Effects 内不再独立掷概率 |
| allowNetworkCrossType | 目标处于网络暴露时，生物/机械之间允许跨类型；不绕过剧情标签和免疫 |
| allowReactions | 默认关闭，夹击、警戒、插件内爆不会再次触发；需要时逐条启用 |
| effects | Buff 效果提交现有 BuffManager；Custom 效果由 handlerId 对应处理器执行 |

在 PieceData 上填写 memeBodyType 与 memeTargetTags。未配置的新资产仍为None，不推测身体类型；B12已按用户确认完成现有17条记录的身体类型和黑衣人标签，详见[正式配置及界面验收](模因双槽界面与B12验收.md)。All类型词条可作用于未配置身体类型的特殊对象，生物/机械专用词条不可。

已有 Buff 的 stacks 仍沿用旧含义：多数普通状态是持续回合，燃烧是强度，-1是永久。durationTurns/magnitude 仅供 Custom 处理器使用。不要用 Stun 直接代替“30%取消行动”的麻痹，也不要用现有 Overload 代替细胞自毁的精确数值；应在后续具体状态实现中处理。

## 解锁和装配

永久解锁保存于 PLAYERPROFILE.memeProgress；角色自由装配保存于 Player.memeSlots。普通新存档和缺字段旧存档通过默认构造获得空数据；显式写入 null 的数据在接入处按空集合处理，不自动解锁任何词条。

```csharp
var profile = GM.Ins.PLAYERPROFILE;
profile.memeProgress ??= new MemeProgress();
bool unlocked = GM.Ins.DM.TryUnlockMeme(memeId, out string error);

bool changed = MemeEquipment.TryEquipOutsideBattle(
    player, profile.memeProgress, GM.Ins.DM.memeCatalog,
    new[] { firstMemeId, secondMemeId }, out string error);
```

两个槽位都必须提交，0表示空槽。同一词条不能重复装配，必须已永久解锁且配置有效。输入数组会复制，不作为角色长期持有对象。战斗进行中免费入口拒绝操作。

```csharp
bool changed = BattleScene.Ins.BM.memeService.TryEquipInBattle(
    currentPiece, new[] { firstMemeId, secondMemeId }, out string error);
```

战斗内必须是当前可控、属于玩家参战列表的角色；动作进行中和外部程序接管期间不能通过此菜单入口操作。确认整套装配扣2AP，空槽替换同样扣费；无变化、非法、未解锁、超槽配置不扣费。调用现有 CostMP(int)，若行动被已有状态中断，遵循旧费用入口已扣AP不返还的行为，但不替换槽位。

暂不通过插件临时授予自由装配权限。插件的固有词条用 ComponentData.memeIds 自动提供；配方、成长或剧情需要永久授予时调用 TryUnlock。

## 词条来源与触发

| 来源 | 配置位置 | 占用自由槽位 | 需要永久解锁 |
|---|---|---|---|
| 自由装配 | Player.memeSlots | 是，最多2个 | 是 |
| 技能固有 | SkillPack.memeIds | 否 | 否 |
| 插件固有 | ComponentData.memeIds | 否 | 否 |
| 棋子固有 | PieceData.innateMemeIds | 否 | 否 |

来源在 BeginCombatAction 开始时读取，按编号升序合并；同一种模因多来源不叠概率。技能伤害各段结算结束后、附加状态和击退前，MemeService.ResolveTarget 处理存活目标；未命中、屏障阻挡和已死亡目标跳过。零伤害但有效命中的目标仍可触发。

每个 MemeActionContext 内，同目标同词条最多判定一次，概率失败和抗性抵抗也消耗这次机会；AOE 的不同目标分别判定。当前判定单位是一次 PieceSkill 调用。正常动画行动为其提供同一个上下文；直接调用 PieceSkill 的多次子结算如属于同一行动，须显式复用上下文：

```csharp
var action = battle.memeService.BeginAction(actor, skill, isReaction: false);
battle.PieceSkill(actor, targets, skill, targetPosition, memeActionContext: action);
```

插件或自定义效果产生的追加技能应使用 isReaction=true 创建上下文，避免将追加攻击当作普通主动行动。当前接口不限制自定义处理器任意调用其他战斗 API；处理器自身须避免无界递归。

## 网络暴露 抗性和预览

```csharp
target.MemeState.NetworkLinked = true;
target.MemeState.SetResistance(memeId, 50);
```

NetworkLinked 只是暴露状态，不改变棋子身体类型。抗性按词条保存，0为无抗性，100为免疫，值限制在0至100。概率判定先抗性后触发概率。棋子 Init 会 Reset 所有本场暴露与抗性；不在 OnDisable 时清理，以免临时隐藏或迷雾影响规则。

B13已将网络暴露改为按节点来源汇总。节点使用 `MemeNetworkNode.TryConnect(target)` / `Disconnect(target)`，重复进入幂等；范围模块应汇总同一目标的多个碰撞体，只在最后一个接触退出时解除。节点禁用/销毁释放自身连接，棋子死亡/Init/销毁及战斗结束清理旧连接；临时隐藏棋子保留连接。

旧 `NetworkLinked` 赋值兼容为独立手动来源：设为false只撤销手动来源，不覆盖节点。清除全部来源须调用 `ClearNetworkLinks()`；节点模块不要再写布尔开关。节点重启、重建或棋子重新Init后，由范围/交互模块重新登记，不自动恢复旧成员。详见[网络节点多来源与B13验收](网络节点多来源与B13验收.md)。

```csharp
var attempts = battle.memeService.PreviewTarget(actor, target, skill, checkResult);
```

预览不掷骰、不记尝试、不施加效果、不发送 AttemptResolved。Outcome 表示是否满足门槛；ChancePercent 是抗性修正后的条件概率，只有 Eligible 时才表示可用触发机会，不包括技能命中率和模式识别成功率。未提供识别结果时，需要识别的词条返回 RecognitionRequired，不预测识别必成功。

所有实战词条判定结果可订阅 AttemptResolved；日志与界面可显示类型不符、标签不符、未通过识别、免疫、被抗性抵抗、概率未触发等原因。效果类型不支持时返回 UnsupportedEffect，不消耗随机也不会部分施加其他效果。

## 自定义效果接口

复杂词条通过 IMemeEffectHandler 接入：

```csharp
public sealed class ConfusionMemeHandler : IMemeEffectHandler
{
    public bool CanApply(MemeEffectContext context, MemeEffectDefinition effect)
        => /* 只读校验所需状态和行为服务 */ false;

    public void Apply(MemeEffectContext context, MemeEffectDefinition effect)
    {
        // 交给具体状态服务记录来源、持续时间及解除规则。
    }
}

battle.memeService.RegisterEffectHandler("confusion", new ConfusionMemeHandler());
```

上述代码是接口示意，不是已实现的混乱行为。CanApply 必须只读，Apply 不再判词条概率，也不得修改共享配置。重复 handlerId 注册返回 false，避免覆盖现有处理器。执行前会检查该词条全部效果是否具备可用处理器。

B10已自动注册cellular-self-destruction与heat-malfunction处理器，并通过TimedMemeDefinitions提供已确认配置模板；SkillPack.memeCureTags默认None，匹配标签的技能才解除新状态。MemeEffectContext.Action保存真实来源，预览为空。具体数值、回合快照、刷新、付费行动及恢复规则见[接入及验收](细胞自毁与散热故障接入及验收.md)。B11已另行确认并实现麻痹、暴力、逆转敌我、屠龙术，注册paralysis、violence、inverted-allegiance、dragon-slaying；行为关系、AI接管、受伤解除、TrueShadow和恢复规则见[行为状态接入及B11验收](行为状态接入及B11验收.md)。未定义词条仍保持禁用。框架不改变现有识别时机、伤害公式和掩体。

## B12 正式目录与双槽入口

默认资源为`Assets/Resources/Battle/MemeCatalog.asset`，通过`DataManager.MemeCatalog`读取，显式目录配置仍优先。稳定编号1001–1006依次为细胞自毁、散热故障、麻痹、暴力、逆转敌我、屠龙术1.0；没有自动解锁或附加角色固有来源。
