# 敌我头顶状态统一与B20验收

日期：2026-10-30。范围为B20现有敌我棋子及PR4-2展示，保留B02其他未验收项目。

## 当前展示

- 使用当前战斗Canvas、原字体、HealthBarFillAnimation、ActionPointPipsUI和BuffCell，敌我共用同一头顶样式。显示原始阵营/名字、真实生命及容量、AP及容量、弹药/能量；状态不改阵营归属。
- 旧Buff显示层数、永久或屏障生命；六种精确模因显示目标普通回合数，网络暴露显示来源数，恢复抗性按词条显示百分比。查询不掷骰、不推进计时、不扣费或解除状态。
- 头顶最多六格，超过六条时显示前五条与“更多状态 +N”；点击状态格打开完整分页详情，每页三条，保留全部条目、施加者与普通回合计时说明。缺图使用文字名称，不以空图丢失状态，也不循环打印缺图警告。
- AP数字保留真实值；点阵最多24点，极端容量继续用数字明确展示，避免大量微小图标或对象无限扩张。正常六点容量沿用现有实心/空心菱形素材。
- 头顶尺寸按屏幕像素保持一致，避让安全区、行动序列、左下信息面板的实际可见图形和聚能按钮。拥挤时按当前行动者、我方、其他角色顺序错位排列，用连线指回本体；完全无空位时收起低优先级标签，不让标签互相覆盖。
- 死亡、隐藏、画面外或相机后方不显示。未唤醒敌人、禁用的角色图形以及被Wall层遮挡的非我方头顶隐藏；不改变目标合法性、AI、战斗关系或迷雾数据。
- 对象Init重置动画、状态缓存和旧详情，临时隐藏关闭详情，销毁/离场移除展示；场景卸载恢复原UI可见性并释放动态对象。

旧敌方血条/Buff区和当前角色旧头顶通过CanvasGroup隐藏，保留原脚本与事件，避免影响命中与伤害预览。隐藏区不拦截鼠标射线。新头顶读取旧HpBarUI的最大/最小伤害后剩余生命快照，退出预览同步清理。旧血条的刷新、FullHp和禁用同时停止旧动画，防止池复用留下Tween。

## 实现位置

- `BattleStatusReadModel`：只读整合旧Buff、精确模因、网络及抗性。
- `PieceOverheadStatusUI`：共享资源、状态单元与预览显示，复用原生命/AP组件。
- `BattleOverheadStatusLayer`：本场实例、定位/避让、可见性、输入与分页详情；从UIManager.Init接入，重复初始化沿用同一实例。
- `BuffCell`：旧面板仍可使用SetData；缺图文字回退和新条目接口共用。
- `HpBarUI`：提供只读伤害预览快照与动画清理；伤害算法未改。

未修改正式预制体、场景、角色配置、状态规则或存档结构，未新增测试到Assets业务目录。
