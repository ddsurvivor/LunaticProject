更新：2026-11-06。开发分支：`dev_feature`。B16 开发改动已完成，状态为待验收；用户授权临时数值，已接入战外侧栏、共享设施模板、逐级费用与确认交互。下文前几节保留 2026-11-04 的存档与关卡接入记录，最新行为见末节。

## 运行行为

- `PLAYERPROFILE.powerSpineProgress` 保存 `PowerSpineProgress.level`。旧档缺字段、字段为 null 或缺少档案时，战斗按零级初始化；负值按零级、超过三级按三级读取。新游戏重置设施进度。
- `PlayerController.Init` 在初始化事件之后读取当前档案，覆盖旧的 Inspector 调试等级。保留原 `powerSpineLevel` 序列化字段作为实际读取等级显示，不再作为正式进度来源。
- 普通关卡按已确认规则：等级 0/1/2/3 对应容量 100/130/160/200，充能倍率 1/1/1.1/1.21，每人费用仍为 50。入场或重开初始化时能量及冷却清零。
- `Assets/Resources/Battle/BurstStages.json` 是明确的场景规则目录，当前将 `PR0BATTLE` 绑定为 Prologue。未列出的场景默认 Normal，不再根据 `chapterNumber == 0` 猜测序章。普通关卡即使玩家章节为零，也能使用已升级设施。
- `PlayerController.burstStageKind` 可显式指定 Normal、Prologue、Tutorial；Unspecified 时读取目录。显式类型优先于目录，旧 `forceDefaultBurstCapacity` 标志始终强制基础规则。序章和教学同时限制容量与充能倍率，不改永久设施等级。

## 升级与保存接入

设施界面通过 `GM.TryUpgradePowerSpine(rules, expectedLevel, out error)` 校验解锁、费用与报价等级。无参 `GM.TryUpgradePowerSpine()` 现也读取正式 JSON 配置并校验费用，不再作为免费升级旁路。成功提升一级，三级返回 false；档案缺失、战斗会话、战斗运行或转场期间均拒绝升级。旧档的 null 进度在允许升级时建立。

接口不会猜测存档槽，也不自动写盘。成功后由正式设施界面按用户选定槽调用既有 `DataManager.SaveData(index)`；档案 JSON 已携带设施字段，战前 JSON 快照也自然包含它。低层 `PowerSpineProgress.TryUpgrade()` 仅负责等级规则，不负责业务限制、费用和写盘。

2026-11-04 时尚无动力脊设施界面；2026-11-06 已根据用户授权的临时数值完成界面与配置，详见末节。

## 配置新关卡

1. 普通关无需添加目录项，保持 Unspecified 即读取永久等级。
2. 新序章或教学关在 `BurstStages.json` 增加精确场景名与类型值，或在该关 `PlayerController` 上显式配置类型。
3. 枚举值：Unspecified=0、Normal=1、Prologue=2、Tutorial=3。目录类型无效时按普通关处理；缺目录资源或空目录也按普通关处理。目录是只读资源，运行时不通过修改它来升级设施。
4. 不因某普通关存在操作提示面板就把它当作教学关；新教学关须明确标记。本轮只配置已确认的 PR0BATTLE，没有擅自修改其他关卡类型。
