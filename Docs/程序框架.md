# 程序框架

本页登记avg_bk音频修复相关入口，既有战斗计划见[原计划](战斗系统开发计划与验收.md)。代码注释遵循[规范](代码注释规范.md)，任务及检查结果见[开发计划](开发计划.md)和[验收和结果](验收和结果.md)。

## 音频与剧情阅读器

- `Assets/Scripts/Playing/AudioManager.cs`：对象池播放音效，独立音乐通道；音效停止版本和音乐版本互不干扰。loop=0取消旧加载请求并播完当前一遍；替换在播循环不取消后续请求；销毁时先停音源再释放句柄。
- `Assets/Scripts/剧本/剧本System.Visibility.cs`：复用本分支CloseStory、HideReader、StopStoryPlayback。关闭立即停止音乐与音效，禁用/销毁兜底，同一会话只清理一次；重新显示恢复播放资格。
- `剧本System.cs`：跳过前取消旧音效，只扫描选项/控制行边界并一次性更新阅读位置；途经行的全部指令不执行，包括变量、奖励、音乐、CG和跳转。仅在落点调用一次Next；选项/控制行保留正常处理，num保留末尾行数。该规则按用户最新要求替代旧的逐行执行机制。
- `剧本System.Commands.cs`：精确分发SOUND/MUSIC，校验及修剪参数，兼容MUSIC(name,1)，关闭后不启动音频。本分支已有Game Over关闭及末尾关闭保持有效。
- `GM.TransitionRoutine` → `AudioManager.BeginSceneTransition`：返回主菜单等转场同时停止音乐和音效并取消旧请求，新场景解除锁定后旧回调仍不能复播。

修正crowd1、shock、wind1对现有crowd01、shock1、wind资源的引用。avg_bk的EXC4-2白噪声STOP本来已修正，未用dev_feature的二进制表覆盖。

## 设置语言

- `Assets/Scripts/游戏设置/SettingPanel.cs`：读取设置前将语言列表设为唯一“中文”选项，保持可点击展开；语言与分辨率列表共用按字体修正选项行高的逻辑，避免展开后文字裁切。语言弹窗顶部锚定输入框底边，保留4个UI单位间距，Dropdown按选项数量收缩时不产生空隙。即使缺少GM也能显示中文。保持现有设置预制体不变。
- `Assets/Scripts/Center/DataManager.cs`：ApplySettings在广播和持久化前将languageIndex归零，兼容旧设置中保存的英文、日文或无效索引。
- `Assets/Scripts/游戏设置/PlayerSettingsData.cs`：保留languageIndex序列化字段，当前仅开放中文。

## CG手动迁移及恢复

- `Assets/Scripts/Editor/ExCGImageBuildProcessor.cs`：静态菜单工具，不继承BuildPlayerProcessor、不注册构建后或编辑器初始化/空闲回调。BuildRelease仅构建，不扫描、迁移或恢复CG，构建成功、失败及中断均不触发恢复。
- `Tools/CG构建/手动迁移未使用的图片`：按EXC引用及场景/Resources直接依赖保留图片，将其余图片和原meta移入 `Library/ExCGImageBuildStaging/files/`；移动前写manifest.json，已有清单时拒绝重复迁移。操作失败保留现场，须手动恢复。
- `Tools/CG构建/恢复临时移出的图片`：仅手动调用Restore，沿用旧清单格式和路径校验；同名文件不覆盖，完整恢复后移除清单并写 `Library/ExCGImageBuildReport.json`。旧构建统计字段保留以兼容历史清单，不再自动更新。
- 扫描菜单仍可单独使用。原正式目录中的RunChecks测试入口已移除，验证脚本只保留在任务tmp目录。
