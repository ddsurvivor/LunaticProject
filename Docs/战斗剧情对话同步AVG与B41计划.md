# 战斗剧情对话同步 AVG（B41）

更新：2026-11-07。状态：**完成（13个场景引用核对及PR0/PR4-2/AVG受控运行范围）**。用户先要求登记，后明确执行B41；本记录保留开工前清单，并补充正式迁移及验收结果。

## 迁移前差异

- AVG 场景引用 `Assets/Prefab/UI/剧本阅读器新.prefab`，依赖 `Assets/Prefab/剧本/AVG正文.prefab` 与 `Assets/Prefab/剧本/剧本Prefab.prefab`，并存在场景局部覆盖；迁移基准是 AVG 场景实际使用的系统及配置，不能只凭预制体名称判断已经同步。
- `Assets/Prefab/Battle/BattleScene.prefab` 仍含剧情系统，并间接引用 `Assets/Prefab/UI/剧本阅读器.prefab` 和 `Assets/Prefab/剧本/剧本Prefab.prefab`。本轮静态扫描发现 13 个场景引用该共享战斗预制体。
- 战斗入口为 `UIManager.logSystem` / `UIManager.StartLog`；`BattleDialogueManager` 持有本关触发配置与播放结束回调。迁移必须保留这些连接及关卡剧本配置。
- `剧本System` 存在拆分的输入、自动播放、显隐、存档及 CG 逻辑；UI 外观一致不能替代这些引用与行为的核对。

登记阶段依据为正式 YAML 引用与代码读取，当时未执行Unity运行。初始明细在忽略的 `tmp/PlanReview20261107/scene-dialogue-audit.json`；本次执行以Unity真实对象、运行与下文结果为准。静态文本中的零引用字段不能直接等同于当前对象绑定失效。

## 开发范围

1. 在 Unity 中核对 AVG 场景的阅读器实例、局部覆盖、嵌套预制体和脚本引用，确定需回收到共享资源的配置及应保留的场景差异。
2. 将共享战斗剧情系统同步到该版本，优先建立正式共享引用，避免逐关复制独立 UI。仅保留战斗需要的接入适配，不创建第二套分叉对话框。
3. 逐场景核对共享实例、覆盖和额外剧情入口，修复 `UIManager.logSystem`、对话完成事件及其他因迁移改变的对象引用；保留原剧本名、触发时机、章节和角色配置。
4. 核对文本、立绘/说话人、选项、滚动与输入、自动播放/跳过、CG 及系统本身已有的相关控件。保留战斗输入阻塞与结束后恢复，不让推进对话的按键同时触发战斗指令。
5. 保持 AVG 原有功能与配置；新增引用经核对后再处理旧资源，不直接删除仍被其他场景使用的旧阅读器。B35 其他面板继续跳过，本项只恢复明确指定的剧情对话系统范围。

## 正式实现

- `Assets/Prefab/Battle/BattleScene.prefab` 的旧阅读器已换为与AVG相同的 `Assets/Prefab/UI/剧本阅读器新.prefab` 嵌套实例，保留对话框、按钮、前景正文、CG、骰子及共享正文预制体的连接；复制AVG实际实例的布局覆盖。13个场景的实际 `BattleScene.UM.logSystem` 和适配引用均有效，因此没有重存任何场景。
- AVG场景、新版阅读器源资产、正文/选项源资产及其他既有预制体保持原文件内容。保留旧阅读器资产供其他引用使用，没有删除资源；没有改变剧本名、触发列表、关卡数值或Build Settings。
- 新增 `BattleDialogueView`，阅读器启用时独立持有战斗暂停，隐藏/禁用时仅释放自己的持有者；设置窗口的暂停不受影响。阅读器通过正常关闭入口完全隐藏后，一次通知本场对话管理器；禁用/卸载不继续旧场景回调。
- `UIManager.StartLog` 统一分发到对话管理器，再由内部显示入口打开阅读器并清空旧UI选中项。重复的完成通知不重复调用回调，管理器禁用清理旧回调；重复聚能就绪提示直接完成调用方，不阻塞后续。
- 战斗适配器启用阅读器的真实时间计时，覆盖逐字、自动/快进、背景/CG/震动与骰子，避免世界暂停使对话停止。AVG阅读器默认仍使用原时间方式，关闭淡出仍用其已有真实时间逻辑。
- 底部“设置”复用本场已有设置窗口。AVG的“记录”实际上打开存档页，本战斗实例禁用该按钮并清空其外部事件，保留原布局；没有增加战斗存档旁路，也没有恢复B35其他面板迁移。

## 失败记录与剩余问题

- 临时迁移脚本初次用了Unity 2021不支持的属性查询API；临时运行脚本初次用了不存在的聚能接口名称。均仅为tmp脚本编译失败，修正后业务和编辑器编译通过。
- 首轮运行50项中2项失败：正文列表包含尚待帧末销毁的旧对象，及开场动画未结束造成设置入口仍被占用；测试改为确认存活对象并完成开场动画。另一次跨关试跑使用了未启用构建的场景名加载，改用隔离编辑器入口，未改正式Build Settings。
- 初次样式比较按名称查找子节点，五个按钮各有同名Image背景/图标，导致10条错误差异；已按实际层级索引重新定位，恢复隔离副本中检查期间的按钮改动，最终231项无差异。不把该临时工具误判记为正式缺陷。
- 原AVG在迁移前的首次编辑器读取已报告3条Odin档案反序列化错误（数组长度为空、TEST、为空），本轮AVG加载仍复现；原场景哈希未改，已分别保留基线日志和运行错误明细。它是独立待核对问题，本轮没有修复或把它隐去后宣称全项目无错误。
- 全部临时脚本、资源、首轮失败及最终证据在Git忽略的 `tmp/B41/` 与隔离工程中；B41临时入口已禁用，测试Story资源已移出Unity导入目录。没有提交Git，未将测试实现留入正式目录。

B41在上述同步和受控验证范围内完成。其他原始剧情、系统键鼠、所有关卡自然流程及发行构建继续保留交付验收边界。
