# 敌人索敌与行动策略

在敌人棋子的 `EnemyController` 上配置以下内容。原 `enemyAIType` 字段和旧枚举数值保留，显示名称为基础行动策略；旧预制体可继续使用旧模式，也可在 Inspector 中改选下面带策划编号的新模式。所有非 Boss 的普通模式默认具备治疗优先和残血撤离逻辑。

## 策划通用行为模式

| 编号与枚举 | 索敌 | 行动 |
| --- | --- | --- |
| 1 `NearestAdaptive` | 最近目标；同时有多个能立即普攻的目标时，改选血量较弱者 | 目标在远程射程内且距离大于其一半、有弹药时远程攻击，否则接近并近战；不为此模式主动装填 |
| 2 `WeakestDefenseShooter` | 场上防御力最低者 | 优先远程攻击；受有效掩体遮挡时先移动到无遮挡射击点；射击后规避半射程内的所有威胁目标 |
| 3 `DamageHunterAOE` | 对自身造成最多历史伤害者 | 距离大于最远攻击射程一半时远程，否则近战；可命中多个目标时优先 AOE 技能或 AOE 普攻 |
| 4 `DamageHunterRangedSkill` | 对自身造成最多历史伤害者 | 可群攻或有低血量技能目标时优先技能；否则距离大于半最远射程时有 1/3 概率尝试远程技能，未触发/不可用时按远近选择普攻 |
| 5 `DamageHunterMeleeSkill` | 对自身造成最多历史伤害者 | 距离严格小于半最远射程时有 1/3 概率尝试近战技能，否则按远近选择普攻 |
| 6 `DamageHunterMeleeOnly` | 对自身造成最多历史伤害者 | 只使用近战攻击，不射击、不装填；也不会用远程攻击引爆桶 |
| 7 `FragileMeleeOnly` | 最低最大生命值或最低防御力 | 只使用近战攻击 |
| 8 `HealingSupport` | 回复优先，普通索敌配置作为进攻兜底 | 移动范围内自身/存活友军低于 50% 血量时优先回复，必要时移动后施放；没有合法回复机会时正常行动 |
| 9 `WoundedRetreat` | 保留索敌配置 | 启用通用残血撤离；该逻辑也默认叠加在其他普通模式上 |

模式 1～7 自带的索敌规则优先于独立 `targetStrategy`。未受到过伤害时，“最高历史伤害”回退到最近目标；历史伤害相同时也优先最近目标。最远攻击射程取近战、远程和攻击技能中的最大值，不计回复技能。

“模式1·范围内血量优先级”提供当前生命值/最大生命值两个中文枚举选项；“模式7·弱者判定”提供最大生命值/防御力两个选项。防御类型默认比较热能（远程）护甲，可通过“防御力比较类型”改成动能或火种。

## 治疗与撤离的共通配置

- `prioritizeHealing`：默认开启；模式 8 即使关闭该开关也会尝试回复。回复阈值 `healHealthRatio` 默认 0.5，严格低于阈值才触发。每名敌人每个个人回合最多主动施放一次回复，防止延迟治疗在尚未生效时被反复释放。
- `isBoss`：Boss 豁免自动撤离。请给 Boss 预制体勾选该字段。
- `retreatWhenLowHealth`：默认开启；`retreatHealthRatio` 默认 0.3，严格低于阈值才撤离。先完成一次当前能执行的攻击，再沿实际导航路径向场地外侧移动；不会为攻击追击、绕路或先装填。无攻击机会时直接撤离，到边缘后停止移动。
- `executeHealthRatio`：模式 4 的“低血量目标”技能优先阈值，默认 0.3。

回复优先于紧急攻击/撤离；已有移动后攻击计划可被回复或残血撤离打断。无有效路径、被束缚或行动点不足时不强行移动。特殊型 `RetreatWin` 保留关卡专用撤离，不叠加通用逻辑。

技能的“敌人 AI 技能用途”是带中文 LabelText 的 `EnemySkillRole` 枚举：自动识别、远程攻击技能、近战攻击技能、回复技能。自动识别会把治疗区、自动治疗 Buff 判定为回复；其他技能根据相对近战射程区分远近。回复技能仍须配置真实回复效果及友军/自身/区域目标规则，标注用途不会凭空生成治疗效果。

模式 2 的引爆优先仍受 `attackExplosives` 开关控制，默认关闭；对具备此能力的敌人单独开启。攻击完成后先处理规避，再考虑下一次引爆/射击，避免连续攻击饿死移动。

## 两个独立部分

| 配置 | 可选内容 | 行为 |
| --- | --- | --- |
| 索敌策略 `targetStrategy` | 标准仇恨 | 保留原算法：嘲讽值 + 最近目标 1 分 + 造成最多历史伤害的目标 2 分；同分沿用原顺序 |
| 索敌策略 | 最近目标 | 忽略仇恨，追逐离自身最近的有效玩家棋子 |
| 索敌策略 | 最低当前血量 | 忽略仇恨，选择当前血量最低的有效玩家棋子；按血量绝对值计算 |
| 基础行动策略 `enemyAIType` | 射击型 | 远程攻击，射击后尝试撤离，范围不足则接近 |
| 基础行动策略 | 技能型 | 优先可用攻击技能，无技能可用时按混合型行动 |
| 基础行动策略 | 混合型 | 优先近战，再考虑远程，最后接近目标 |
| 基础行动策略 | 特殊型 | 沿用关卡 `RetreatWin` 撤离逻辑；配置该类型需提供对应组件与目标点 |

死亡、隐藏、不可被攻击的玩家棋子不参与索敌。最近和最低血量策略同值时选择列表中的第一个有效目标。仇恨指示及移动预览使用同一套索敌规则。

## 条件切换

`strategyRules` 是从上到下检查的规则列表，第一条满足全部条件的启用规则生效。每条规则同时提供新的 `targetStrategy` 和 `actionStrategy`。

支持的条件：

- 自身血量比例不高于 `healthRatio`，例如 `0.3` 表示当前血量不超过最大血量的 30%。
- 可索敌目标数量不多于 `count`，只统计存活、显示且可攻击的玩家棋子。
- 存活且激活的友军数量不多于 `count`，不包含敌人自身。

示例：基础配置为标准仇恨 + 混合型；添加规则，自身血量比例不高于 0.3，切换为最近目标 + 射击型。也可以再添加一条规则，当可索敌目标数量不多于 1 时改用最低血量 + 技能型。两个规则同时满足时，列表靠前的规则生效。

每次规划时重新评估状态；条件解除后恢复基础策略或下一条匹配规则，不永久锁定阶段。空条件规则不触发。切换策略后废弃旧的移动后攻击计划；未发生切换且未触发紧急回复/撤离时继续保留已经承诺的计划。切换后的行动策略也可以选择新的编号模式，此时其内置索敌规则生效。

## AOE 攻击选点

`maximizeAOETargets` 默认开启，适用于普通近战、远程和主动技能。以技能的正式目标规则判断是否多目标：`EnemyAll` 或 `All`。`Enemy`、`FarthestEnemy` 等单目标技能仍保持单目标规则。

比较目标位置、两目标中点、群体中心，以及圆形覆盖交点；扇形和弧形还比较每 5 度的朝向。所有候选落点受施放距离限制，并使用 `SkillTargeting.Query` 计算实际命中目标，沿用层高、存活、阵营和范围形状规则。Nova 始终以自身为中心。

优先命中更多敌对目标；同数量时优先包含索敌目标，再减少可能命中的友军。允许爆炸半径命中施放距离外的目标。移动后和正式出手前按新位置重新计算选点，攻击动画、范围预告和最终命中共用该落点。这是候选采样优化，不保证连续空间中的数学最优解，也不会为提高命中数额外消耗移动行动力。

## 利用爆炸物

敌人的 `attackExplosives`（Inspector 名称：允许攻击爆炸物）默认关闭。只对希望具备该能力的敌人或敌人预制体开启。

开启后，敌人在正常行动规划中会优先检查场景内注册的普通爆炸桶和电浆爆炸桶。桶必须存活、显示、尚未引爆，且本次爆炸或电浆脉冲能伤害至少一个玩家。检查使用桶自身的爆炸半径、碰撞层、技能阵营/层高、伤害预览和屏障规则，不只比较玩家到桶的距离。

敌人只选择当前攻击距离和范围形状能命中、能造成正伤害、且资源足够的攻击。射击型用远程攻击，技能型优先技能，混合型优先近战再远程。空弹匣时需要保留装填和攻击的行动点；特殊型继续专用关卡行为。多个可用桶优先选能影响更多玩家的桶，再选离自身更近的桶。没有可用桶则继续原来的索敌与行动方式，不为引爆桶额外绕路。

攻击环境目标时只在该次技能副本中允许命中桶，不修改技能资产，不让单目标攻击变成群攻。桶仍通过原来的受击/死亡事件触发爆炸或电浆脉冲；普通桶生命较高时可能需要多次攻击。场景中的桶需保留原有的受击/死亡事件绑定。

普通桶死亡后的延迟爆炸使用运行时技能副本继续结算，避免被“施法者死亡”检查拦截。普通角色的死亡依然会中止攻击。

## 验证

- `tmp/Tests/EnemyTargetLines/Run.ps1`：索敌、组合条件、优先级、策略恢复、承诺计划失效，以及原仇恨线/范围交互回归。
- `tmp/Tests/BattleRegression/Run.ps1`：正式范围查询下的圆形爆炸、扇形、弧形、Nova、限距、层高及单目标限制回归。
- 同一战斗回归还覆盖爆炸物开关、同阵营环境目标、碰撞层、无玩家/已触发/隐藏/距离不足/无伤害的桶、最多玩家优先、资源不足和死亡桶的伤害结算。
- 决策回归直接编译正式 AI 行动/索敌代码；使用场景、导航、动画替身验证半射程边界、历史伤害、低防目标、技能概率、群攻/低血量优先、移动后回复、Boss 豁免、攻击后规避/撤离、绕掩体以及与爆炸物开关的组合。
- Unity 内建议用三个分散/聚集的玩家棋子，分别检查普通攻击与主动技能；将敌人血量降到阈值后观察其目标线和行动切换。
