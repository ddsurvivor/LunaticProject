# 战斗表现回归

运行 `./Tests/BattlePresentation/Run.ps1`（.NET 8，无额外 NuGet 依赖）。
同时运行 `./Tests/BattleRegression/Run.ps1` 检查原有伤害、被动和资源结算规则。

本测试直接编译生产版本的 PieceDisplay、TimeManager、LifeTime，
用可控的 Unity 时间/渲染对象与 Tween 调度替身覆盖短长动画、低帧率、回调重入、
死亡中断、暂停/恢复、连续命中、聚能定格和池对象复用。
它不替代 Unity Play Mode 对实际场景、DOTween 弹道、UI 和音效的视觉验证。

## 实现约定

- 保留所有序列帧列表及其序列化字段，无需重配角色、场景或预制体。
- 按已有 6 FPS 播放（移动 12 FPS），自动用序列中点帧出手。
  没有动画或技能索引无效时，在下一次非暂停更新出手并完成，不挂起战斗。
- 普攻、技能、敌人攻击和警戒共用动作流程：出手 -> 弹道实际到达（无弹道直接命中）
  -> 原有伤害结算和受击反馈 -> 等待攻击与受击播放结束。
- 动作快照保存目标集合、技能、行动类型和施法位置；支付资源在动作开始时进行。
  死亡/禁用取消未完成动作，不补发伤害，不退还已支付资源。
- 一次性动画旧接口的正 duration 现在表示“播完回待机”，不再截断帧序列。
  聚能受击的负 duration 仍保持最后一帧。攻击中受击会在攻击结束后播放受击帧，
  扣血、跳字及震动仍在命中时触发。多段伤害保留逐段规则与跳字，不反复重启受击。
- 战斗动画、弹道、跳字使用缩放时间；受击减速用真实时间恢复，显式暂停保存剩余时间。
  并发减速采用更慢速度和更长剩余时间。禁用 TimeManager 恢复原时间与物理步长。
- 夹击防重入锁跟随整个实际动作；AI 和结束回合等待表现完成。
  检定技能等待骰子显示结果后才开始施法。

## Unity 场景验收

1. 对短帧/长帧角色分别执行近战、远程和非零 animationIndex 的技能。
2. 远程命中时检查弹道到达、扣血、跳字、受击帧和慢动作是否对齐；无弹道攻击也要验证。
3. 多目标、多伤害包、闪避、致死、聚能定格、警戒和夹击各执行一次。
4. 在出手前、弹道飞行中和受击停顿中暂停再恢复；快速反复暂停。
5. 动作中击杀/禁用攻击者，确认无迟到伤害且不锁回合；假死复活后重新攻击。
6. 连续战斗退出/重进，确认时间比例和池对象状态恢复，旧计时不回收新特效。

自动中点是无需配置的通用打击点，无法从图片内容识别每个角色美术上最准确的接触帧；
视觉验收时应特别检查这一点。
