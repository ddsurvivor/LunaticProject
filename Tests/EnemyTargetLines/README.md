# 敌人目标指示线回归

运行 `./Tests/EnemyTargetLines/Run.ps1`（.NET 8，无外部包）。
测试直接编译 AIController.Targeting、EnemyController.TargetLine、ClickManager.TargetLines 的生产代码，
用目标、移动状态和 LineRenderer 替身验证目标选择、可见性、实时端点与样式恢复。
真实射线拾取、EventSystem、NavMesh 有效落点及实际材质表现需在 Unity 中验收。

## 操作约定

- 仅玩家可操作回合显示意图线；敌方回合、战前巡视、胜负后关闭。
- 鼠标移入激活的存活敌人显示目标线，移出到空白/其他对象/UI 关闭悬停线。
- 点击敌人保持该敌人的线；移出不关闭。悬停另一个敌人可临时显示其线。
- 点击另一个棋子（含快捷键）、右键、结束回合会清除保持状态。
- 指示线逐帧更新敌人位置、目标位置和目标选择；正常显示优先采用 AI 已承诺攻击计划。
- 我方规划移动时使用导航路径的有效落点，按同一仇恨/嘲讽/距离规则预测目标。
  使用只读位置覆盖，不临时移动真实棋子、不改仇恨或 AI 计划。
- 移动预览仅显示目标是移动角色的激活敌人，呼吸透明度与宽度；真实行走时跟随当前位置。
  目标改变时立即关闭旧威胁线、激活新威胁线；移动期间过滤优先于悬停和点击保持。
  无效导航路径不显示旧落点预览。结束规划/移动后，清理临时线和呼吸样式。
- 显示时激活指示线承载物体和组件；关闭独立指示线物体，但不关闭敌人根对象。
- 回合结束或改选会取消未确认的移动规划，防止旧预览在下一回合恢复。
- 复用现有 tagetLine 组件及原色、曲线样式，不需要重新配置场景/预制体。

## Unity 场景验收

1. 悬停敌人，再移到空白、其他敌人、UI，检查线与描边均正确进出。
2. 点击敌人并移出，检查持续显示；点击我方/另一敌人、快捷键改选和结束回合检查关闭。
3. 规划移动至不同可达点/不可达点，检查预测目标切换、导航截断位置及呼吸效果。
4. 确认移动、取消规划、撤回移动，检查线条端点实时更新且样式恢复。
5. 敌人/目标移动、死亡、隐藏，检查线不滞留在旧位置或旧目标。
