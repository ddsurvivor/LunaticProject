# 速度条回合

运行 `./Tests/SpeedTurns/Run.ps1`。测试直接编译生产用 `SpeedTurnQueue` 和 `BattleManager.SpeedTurns`，通过轻量场景替身逐步推进协程；现有 BattleRegression 另外覆盖实际 Buff 结算实现。

## 配置与规则

- `PieceData.speed`：每次速度时钟累加值，默认 10；`PieceController.turnSpeedOverride` 大于 0 时覆盖该棋子速度。旧数据缺省或非法速度回退为 10。
- 满 100 获得个人回合，扣除 100 并保留溢出。同一时钟内按实际跨越 100 的先后排序；完全同刻使用稳定顺序，初始注册交错排列敌我。
- 等待玩家输入、AI 决策、移动和战斗动画期间停止累加。玩家保留个人 AP，耗尽、待机、不可控制或死亡时结束；敌人只决策当前棋子，无法继续行动也结束。
- Buff 生效、持续时间、被动回合结束均按所属棋子结算。警戒只在该棋子下次行动时解除。聚能只恢复当前棋子 AP。
- 阵亡、隐藏和未激活敌人不进入速度条；复活、增援、新召唤物以 0 进度加入。
- 原有关卡对话、增援、坚持回合胜利继续使用独立的标准轮：每 10 次速度时钟增加一轮，速度 10 的单位每轮约行动一次，不按全队的个人回合次数累计。
- UI 自动挂到现有战斗 Canvas 顶部中央，不需要修改场景引用。`PieceData.turnPortrait` 可指定头像；玩家默认复用信息面板头像路径，其他棋子回退为场景精灵。蓝色为我方、红色为敌方、金色为正在行动的棋子，右侧为起点、左侧为满条。

## 验收

19 项自动测试覆盖速度比例、到达次序、同速稳定性、溢出、高速连续行动、死亡移除、复活/增援注册、个人开始/结束、输入归属、停表、移动/动画等待、待机、眩晕和停止战斗。

仍需在 Unity Play Mode 中检查不同分辨率、同进度头像重叠、实际头像素材及敌人移动/技能表现。现有场景未在本次自动测试中运行。
